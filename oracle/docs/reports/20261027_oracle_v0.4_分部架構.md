# Oracle 個股模型 v0.4：命題＋營收分部架構（2026-10-27）

成品：`oracle/dist/20261027_Oracle個股模型_v0.4.xlsx`（＋同名 HTML）。分支 `claude/oracle-v0.4-seg`，PR #183（draft，未合併）。

## 1. 結論

- **命題答案**：OCI 的 backlog 能轉成營收，但在可觀察的市場價格下報酬低於資金成本。情境 B（基準）FY2029 OCI 營收 936 億美元（其中 AI 算力 790 億），為公司路徑 1,140 億的 82%；OCI AI 營業利益率（扣 AI 折舊與機房租金後）只有 6.3%，AI 增量 ROIC 1.7%，遠低於 WACC 12.2%。AI 擴張主要是把軟體現金流換成機房與 GPU，沒有創造價值。
- **目標價與建議**：加權目標價 **US$133.2**（DCF 55.5 × 50%＋分部加總 211.0 × 50%；情境 A／B／C＝151.9／140.1／100.7，權重 25／50／25），現價 US$126.06（2026-10-26），上檔空間 **+5.7% → 中立**。市場共識目標價 237.4，本模型低 44%。
- **收支關卡**：FY2027–FY2031 自由現金流扣股利合計，情境 A／B／C＝**+128／+90／+18**（十億美元）。FY2027、FY2028 為負（情境 B −31、−19），情境 B 需新增投資級債約 16、不需新股或高息債；調整後槓桿峰值 3.93 倍（情境 C 5.00 倍，超過 4.5 倍上限，但缺口小、不需新債）。五年合計轉正的前提是只建已簽站點（見第 5 節預設 1）。

## 2. 為什麼換架構

v0.3.1（2026-10-22）沿用 CoreWeave 樣板：OCI 以「MW × 每 MW 收入」驅動，SaaS、軟體、硬體、服務壓成「傳統事業」四條成長率、共用一個 EBITDA 率 54.26%；OCI 利潤以 EBITDAR 率校準；評價 DCF 45%＋分部 EV/EBITDA 55%（OCI 6x、傳統事業 15.02x）。結果：基準目標價 84.2（保守 77.4、積極 91.9），全部「賣出」；但 DCF 腿只有 8.1、分部腿 146.5，兩腿差 18 倍，目標價幾乎全由倍數決定；FY27 營收 83.1 低於指引 7.7%，列為結構性限制。
Andy 2026-10-27 的原則：個股模型要依主要命題建模，再配合公司營收分部形成損益表，才能和公司與市場口徑逐列比較。Oracle 的命題確實是算力出租（OCI），但營收還有 SaaS、授權、支援、硬體、服務五條，且官方分部是 Cloud and software／Hardware／Services；v0.3.1 看不出差異來自哪一條業務。

## 3. 結構

| 官方分部（10-K 附註 13） | 營收線（新聞稿） | 命題子列 | 驅動 |
|---|---|---|---|
| Cloud and software（雲端與軟體） | Cloud Infrastructure（OCI） | OCI AI 算力 | 命題模組：計費 MW × 每 MW 年收入（Tokenomics 持有成本 × k） |
| | | OCI 其他（非 AI） | Q1 殘差 × 成長路徑（20% → 8%） |
| | Cloud Applications（SaaS） | — | 近四季年增 11.1% → 長期 8% |
| | Software license | — | −9.3% → −2% |
| | Software support | — | +0.8% → −1% |
| Hardware | Hardware | — | +8.0% → 0% |
| Services | Services | — | +9.2% → 3% |

分部利潤：Cloud and software＝OCI AI 貢獻（AI 營收 − Tokenomics 營運費用 − 機房租金 − AI 折舊）＋其餘營收 × m_sw（Q1 FY27 校準 64.5%，對照 FY2024 64.1%）；Hardware、Services＝營收 × FY2026 利潤率（65.4%、26.7%）；減未分攤費用（研發、管理、攤銷、SBC）＝GAAP 營業利益。

驅動 → 推導對照（完整表見 README）：MW 速度／上限／延誤 → 計費 MW → OCI AI 營收；新增 MW × IF_CapexIT（FY27 以指引中點 92.5 為錨）→ AI 資本支出 → AI 折舊（6 年）→ 分部利潤 → EPS；AI 資本支出 × 客戶出資覆蓋比 24.3% → 預付；自由現金流 − 股利 → 融資瀑布（現金 → 投資級債 → 新股 → 高息債）。

## 6. v0.4 vs v0.3.1 目標價差異拆解（情境 B 對 v0.3.1 基準）

v0.3.1 基準 84.2＝DCF 8.1 × 45%＋分部 146.5 × 55%。v0.4 情境 B 140.1＝DCF 60.1 × 50%＋分部加總 220.2 × 50%。

| 項目 | 變動 | 說明 |
|---|---|---|
| 評價權重 45／55 → 50／50（以舊兩腿計） | −6.9 | 方法 |
| DCF 腿 8.1 → 60.1（× 50%） | +26.0 | 營收結構（SaaS 等各自路徑、OCI 含非 AI）、AI 營運費用改由 Tokenomics 推導、汰換依世代年份；容量觸頂後資本支出降到汰換水準，FY2029 起自由現金流為正 |
| 分部腿 146.5 → 220.2（× 50%） | +36.8 | 其中 OCI 倍數 6x → 6.34x：+2.5（反事實重算）；其餘 +34.3 來自錨定改為 FY2028 年底企業價值（v0.3.1 錨定 FY29 後折回）、其餘業務 EBITDA 加回 SBC（同業口徑）、OCI AI EBITDA 以租金後計 |
| 市場資料（現價 129.13 → 126.06） | +0.2 | WACC 股權權重（已含在上兩列） |
| 合計 | +55.9 | 84.2 → 140.1；再經情境加權（A 151.9、C 100.7）→ 133.2 |

評等由「賣出」（v0.3.1 自身規則：低於現價 85%）變為「中立」（五級規則）：目標價上升，且評等規則改為五級。
