# Oracle v0.4.3 → v0.4.4：2026-11-02 股債增資納入

## 1. 結論

**增資改變了「資金缺口要如何補」的答案，但沒有改變評等。** 2026-11-04 交割的 20B（新股 10、票據 10）已經補掉模型原本在 FY2027–FY2028 要補的缺口：三個情境之後都不必再發投資級債、新股或高息債，FY2027–FY2030 外部融資合計 20.0，剛好等於公司在投資人日承諾的上限 20，沒有超出。加權目標價 73.22 → **74.67**（+1.44），以 2026-11-03 收盤 126.19 計，上檔空間 −40.8%，**放空維持**。收支關卡（情境 B，FY2027–FY2031 自由現金流扣股利合計）72.76 → **72.70**，幾乎不變。

- **翻轉的數字：** 情境 C「是否需要發新股或高息債」由「需要」變「不需要」。v0.4.3 的情境 C 要在 FY2027–FY2028 發新股 2.41，現在由已發生的增資取代。情境 B 原本在 FY2028 要發投資級債 18.62，也改為 0。
- **公司實際走的路，比模型 B 更偏股權。** v0.4.3 的情境 B 判斷「不需要發新股」，公司還是發了 10B 新股。不過發行價 116 遠高於模型 DCF 每股價值（約 42），所以對每股價值是加分。
- **槓桿變差，但只有一年。** 新票據在 FY2027 就進帳，情境 B 的調整後槓桿峰值由 4.43 升到 **4.64**。
  - 這是 FY2027 單年超過 4.5，FY2028 就降到 3.98。
  - 因為超過模型的投資級上限 4.5，情境 B 在 FY2027 可新增的投資級債額度為 0。
  - S&P 的降評條件是「持續」大於 4.5，而且 S&P 的調整後負債含未起租租約，與模型的口徑不同，不能直接比。
  - 情境 C 由 5.20 升到 5.35。
- **緩衝很薄。** 情境 B 的 FY2028 期末現金 10.879，只比最低現金 10 多 0.88。公司上限 20 已經用滿，情境 B 只要再有不利變化，就會超出上限。
- **評價日與現價：** 評價日維持 2026-08-31（FY27Q1 資產負債表；FY27Q2 到 11-30 才結束，資料還不存在）。股數、現金、借款以增資作 pro forma 計入。現價由 126.06（2026-10-26）改為 126.19（2026-11-03）。rf、目標價時點（2027-10-31）不動。

## 3. 模型改了什麼

- **In 頁新增 I2 節**（增資，已發生）：`ex_sh`、`ex_px`、`ex_eq_gross`、`ex_eq_net`、五檔票據面額與票息 `ex_n29…ex_n46`／`ex_c29…ex_c46`、`ex_nt_par`、`ex_nt_r`、`ex_nt_net`、`ex_date`、`ex_frac`（FY2027 交割後 208/365 年）、`ex_divq`（新股在 FY2027 領 2 次季股利，[Assumed]）、`fin_cap`（上限 20）。
- **K 節新增投資人日三列：** `gi_fcf29`、`gi_nd29`、`gi_rev30`。
- **股本：** 新股 0.0862 十億股從 FY2027 期末起計入。FY2027 的稀釋股數按交割後年數加權。評價用完全稀釋股數 3.089 → 3.175。
- **現金：** CF 頁新增「已發生增資淨額」一列，FY2027 為 19.9，排在瀑布之前；同一筆現金在 FY2027 剩餘期間有利息收入。
- **負債：** 借款合計加票據面額 10.0。利息費用加 7.768% × 10.0（FY2027 按交割後年數，FY2028 起全年 0.777）。到期以相同票息展延，與既有借款規則相同。
- **資金瀑布：** 順序不變（現金 → 投資級債 → 新股 → 高息債），起點多了 19.9。投資級債額度扣掉新票據。
- **與原有融資假設的對應（不重複計入）：** 模型的瀑布按缺口內生，FY2027 沒有另外假設一筆「計畫融資」。v0.4.3 的瀑布在 FY2027 沒有融資；FY2028 情境 B 發投資級債 18.62，情境 C 在 FY27–FY28 發新股 2.41。本版這些都被已發生的增資取代，所以同一筆缺口不會算兩次。
  - 公司 FY27 計畫融資約 40（v0.1a `fin.fy27.plan`）＝Q1 ATM 20（已在 FQ1 股數與現金內）＋本次 20。
- **評價（Val）：**
  - 淨借款 97.11 → 87.21：加票據面額 10.0，減票據淨額 10.0，再減新股淨額 9.9。
  - WACC 的股權權重用新股數，負債權重加入新票據：10.514% → 10.452%。
  - 分部加總用 CF 頁 FY2028 年底的借款、現金與股數，會自動帶入增資。
- **新檢查列（CF 頁 GATE+8～+11）：** 列出 FY2027–FY2030 模型外部融資合計（增資毛額＋瀑布三項）、公司上限、超出金額、超出年份。依判斷題預設，上限不設成硬限制。

## 4. 每股價值拆解（逐步完整重算；`scripts/decomp_v044.py`，結果在 `data/decomp_v044.json`）

方法：每一步都疊在前一步之上，用完整模型重算（build＋LibreOffice）。S2–S4 把瀑布三列（投資級債、新股、高息債）凍結在 S1 的值，S5 再解凍，這樣可以把瀑布的反應單獨拆出來。S0 用 v0.4.4 程式、把增資全部設為 0、現價設為 126.06，結果 73.2244042213954，與 v0.4.3 成品完全相同。

|---|---|---|---|---|---|

| S1 現價 126.06 → 126.19（WACC 股權權重、瀑布新股上限） | 73.2175 | −0.007 | 41.698 | 104.737 | 72.76 |

| S3 現金增加（新股淨額 9.9＋票據淨額 10.0；利息收入） | 77.6415 | **+6.648** | 47.340 | 107.943 | 74.68 |
| S4 負債與利息（票據面額 10.0、票息 7.77%、WACC 負債權重） | 74.6887 | **−2.953** | 44.640 | 104.737 | 71.51 |
| S5 瀑布後續變化（解凍：投資級債 A 4.87、B 18.62 → 0；C 新股 2.41 → 0） | 74.6671 | **−0.022** | 44.640 | 104.694 | 72.70 |
| **合計** | | **+1.443**（＝74.6671 − 73.2244） | | | |

- **按工具分：**
  - 新股（股數＋淨額 9.9，瀑布凍結）合計 **+1.083**（S1 → 只有新股 74.3008）。發行價 116 高於 DCF 每股價值，DCF 加 2.0；分部加總每股約 109，與發行價接近，所以分部加總幾乎不變。
  - 票據（現金 10.0＋面額 10.0＋票息）合計 **+0.388**。票據本身不改淨借款；加分來自 WACC：負債權重升高，而模型的稅後 kd（5.8% × 0.849）低於股權成本。判斷題 1 說明這個加分偏樂觀。
  - 瀑布 **−0.022**：情境 C 原本要用 2.41 的新股補足的現金沒了；情境 B 少掉 18.62 的投資級債，但淨借款不變，所以效果近 0。
- **收支關卡 B −0.07 怎麼來：**
  - 票息每年 0.78（稅後約 0.66）。
  - 新股股利每年 0.17。
  - 多出來的現金有利息收入。
  - 瀑布裡少掉的投資級債利息（5.8% × 18.62，從 FY2029 起）。
  - 以上大致互相抵銷。
