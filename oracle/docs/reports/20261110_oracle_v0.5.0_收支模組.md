## 3. 與 v0.3.1 收支模型的差異（不會逐位相同的原因）
1. 營運現金由分部損益 → 淨利起算；v0.3.1 用 EBITDAR 率 × 營收。
2. 排程還本在基準假設展延；v0.3.1 當作現金用途（五年 39.9）。
3. 瀑布沒有額度與可轉債步驟（Oracle 無可轉債）；債務上限由債務／backlog 改為租賃調整後槓桿。
4. RPO 排程改為同口徑檢查，不再有「新簽約率」。
