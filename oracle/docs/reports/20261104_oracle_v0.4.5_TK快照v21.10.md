# Oracle v0.4.4 → v0.4.5：Tokenomics 快照換 v21.10（基準與 Sens 都不變）

**結論：** 數值完全不變（加權目標價 74.67、放空）。v21.10 只改 `IF_NonNV_Out_TPU`／`IF_NonNV_Out_Trn`，本模型的快照不含這兩個名稱（只讀 IF_HoldEcon、IF_CapexIT、IF_OpexGW、IF_DeprLifeIT、IF_GPUhrEcon），所以差異只有版本與快照說明文字。Sens 重跑，值逐一相同。

## 做了什麼
- 用 `tools/tokenomics/import_tokenomics.py` 產生新快照 `data/tokenomics_snapshot_v21.10.json`。
  - 來源：`20261104_Tokenomics_v21.10.xlsx`，master eded8e6（`model/CURRENT` 已核對），2026-11-04 取數。
  - 名稱清單取 v21.9 快照的名稱（MAG 清單，42 個，optional 3 個；與 #308 相同，不用 `data/tokenomics_names.txt` 的 v0.3 舊清單）。
  - `--check` 通過。
  - 與 v21.9 快照逐值比對：值全部相同（只有檔名、版本、commit 不同）。
- 舊檔移到 `_待刪除/`（沿用本資料夾慣例）：
  - `data/tokenomics_snapshot_v21.9.json`
  - `dist/20261104_Oracle個股模型_v0.4.4.xlsx`、`.html`
  - 例外：v19.0 快照保留，因為 `scripts/sens_v04.py` 的營運費用基準要用（同 #308）。
  - 敏感度結果 `data/sens_v04.json` 是固定檔名，原地重寫。
