## A. 建設延誤模組（新；全部參數放 `company.json`，Excel 公式與 HTML 引擎兩邊實作，cmp31 加比對項）
1. **延誤月數** `scenarios.delayMonths`：保守 6、基準 3、積極 0（[Assumed]；依據：Project Jupiter 天然氣管線延後近 6 個月至 2027-02-01、燃料電池空氣許可待決，事實總帳 `event.jupiter.fm`；基準取半）。作用：**計費／營收的 MW**＝原併網路徑往後平移延誤月數（以期間長度內插）；合約上限不變。
2. **GPU 資本支出照原時程**：成長型資本支出仍依「未延誤」的併網路徑支出（GPU 與網通已採購／已交貨等電），客戶出資覆蓋比同樣依原時程；**折舊**自延誤後的投入使用時點開始。產出「閒置資本」列＝已支出但尚未產生收入的累計資本支出（期末），並在一頁摘要以一句呈現其峰值。
3. **租約起租連動** `leases.uncommenced.delayLink`（0–1，預設 0.5 [Assumed]）：未起租 288B 中有此比例的起租時點隨延誤月數後移（開發商交付晚），其餘照原時程（Oracle 自身的設備或電力延誤不影響租約起租）。替代 0／1 列敏感度。
4. **延誤罰則或服務抵減** `defaults.delayPenalty`：延誤期間「應計費而未計費」營收的百分比，預設 0（公司未揭露合約條款；標「不存在／未揭露」），敏感度 5%／10%。
5. **預付**：客戶預付不因延誤退還（預設），退款風險列已知限制。
6. **驗證不變性**：所有延誤參數設 0 時，三情境目標價與 v0.1 完全相同（cmp31／--vs-dist 對 v0.1 成品，以 --expect 列出新增列，其餘 0 差異）——這是方法新增的驗收，請在報告列出。

## B. 租賃調整後槓桿與投資級上限
1. **租賃負債**：每期末＝剩餘租金的現值，折現率取 10-K 加權平均 5.7%（`lease.discRate.fy26`，[Verified]）；涵蓋在帳租約與未起租租約（已起租部分）。
2. **調整後槓桿**＝（總債務＋租賃負債）÷（EBITDA＋當期租金）（S&P 口徑近似：租賃調整債務 ÷ EBITDAR）；**投資級上限改為調整後槓桿 ≤ 4.5×**（S&P BBB- 降評門檻，事實總帳 `rating.sp`；[Interested-party] 二手轉述，註明），取代 v0.1 的總債務 ≤ 4.0× EBITDA；超過部分照原瀑布走股權再走高息債。敏感度 4.0×／5.0×。
3. 一頁摘要與融資頁新增「調整後槓桿路徑」與「距 4.5× 的空間」；任一期超過 4.5× 時一句標示「需股權或失去投資級」。
