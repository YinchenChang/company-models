## 照預設的四項（14:16 那一輪列出）
1. 先拿 Oracle 試做，通過後再做 Nebius、WhiteFiber、CoreWeave。
2. 新增「收支型個股」版面：資金缺口放在命題之後、驅動因子之前。
3. 動態展示用「預先算好的切換」，放棄自由滑桿（不再養第二套瀏覽器引擎）。
4. 站點表先照搬（不驅動 MW 路徑）。

## 範圍
- 新增六張工作表：Fund、RPO、Sites、Debt、Lease、RevDCF（`oracle/funding_v05.py`）。
- 只新增、不改既有儲存格：既有十頁與 v0.4.7 逐格相同，加權目標價與投資建議不變。
- 現金數字只留一組：來源與用途一律引用 CF 頁，不搬舊版以 EBITDAR 率推算的現金。
- 反向 DCF：`scripts/reverse_v05.py`，一次動一個驅動、整本重算反解到現價與中立門檻。
- 資金缺口壓力表：`scripts/stress_v05.py`，情境 B 延誤月數 × 客戶出資覆蓋比。
- HTML：共用產生器加兩個可選節 `funding`（緊接 thesis）、`revdcf`（緊接 valuation）；其他公司輸出不變。
