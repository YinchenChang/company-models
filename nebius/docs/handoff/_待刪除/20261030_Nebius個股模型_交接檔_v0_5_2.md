## 1. 這是什麼（命題）
Nebius（NBIS）的資金與評價模型。命題：Nebius 用**客戶預付款**而非資產層債務支應大部分擴張資本支出——檢驗在 Tokenomics 錨定的每 MW 經濟性下，擴張到 5 GW 合約電力能否不依賴持續的股權與可轉債稀釋，也就是 CRWV「Backlog 不是現金」的對照組：**預付款是否讓 backlog 真的變成現金**。

**標題**：「預付款，能把 Backlog 變成現金嗎？」（`company.json` → `texts.title`）。副標題一句話答案由模型現值帶入（v0.3 第 2 輪）：預付只覆蓋約 36% 的資本支出，$75.9bn 缺口靠債與新股；每 MW 收入是打平租金的 0.9 倍，現價要 2.5 倍（基準情境；隨情境切換）。

**目前答案（v0.5，工作單 v0.5a）**：預付款是真的現金（上半年約 4.55bn），但只覆蓋約 36% 的資本支出，$75.9bn 缺口靠債與新股；新增產能按長約價（k＝0.89，證據價格不變、除以 Tokenomics v18.0 成本），每 MW 年收入（9.2–10.4 US$m）仍收不回 Tokenomics 打平租金（10.3–11.6，v18.0），擴張愈快缺口愈大：三情境目標價 保守 $29.5／基準 $21.4／積極 $19.4（v0.4：$29.7／$22.0／$20.4），全部「放空」（現價 $249.87，放空門檻 $212.4）。容量 × 價格 3 × 3 九格全部低於放空門檻（最高 $46.6）。v0.5 只動一個假設：首期末爬坡係數 60% → 100%（依 v0.1c 原規則重新校準；基準 FY26 營收 2.34 → 2.86），仍低於公司指引 3.0–3.4——只靠爬坡無法閉合（到下緣需 111%、到中點需 126%，皆超過 100% 上限），剩餘差距 0.34 在 F2 閉合橋列為「單價／口徑未解」，不硬調 k 或期初可計費 MW。信心中等：最大的不確定仍是 k_長約（市場長約只有 IREN–Microsoft 一筆已證實；Nebius 自身合約未揭露容量），k 隨 Tokenomics 成本移動；另新增兩項只作敏感度（不改點位）：新產能簽約率 75%／50%（基準 $21.4 → $12.9／$4.9）、方法並列 B（DCF 腿為 0 時權重全移至 EV/EBITDA：保守 $53.7／基準 $38.9／積極 $35.3，評等仍依 A，仍全部低於放空門檻）。

模型同時輸出 HTML（互動、可調輸入）與 Excel（全部活公式），兩者數字必須一致（cmp31 三情境各 438 項＋FY27 錨定另跑）。

## 3. 模型結構與因果
**因果主軸**：已連網 MW → 可計費 MW → 營收 → EBITDA → 營運現金（＋客戶預付）− CapEx → 融資缺口 → 瀑布（資產擔保融資 → 可轉債 → ATM 股權 → 高息債）→ 股數與淨負債 → DCF＋EV/EBITDA → 目標價。

## 10. 如何重建
1. 環境：LibreOffice Calc（`soffice --version`；缺時 `apt-get install -y --no-install-recommends libreoffice-calc-nogui`）、Python `openpyxl`、`playwright`（1.56.0）＋ Chromium、Node.js。
