### 11.1 結論
- **敏感度異常的原因在主模型本身，不在敏感度表**。敏感度表與主模型用同一套計算（`fA` → `runFunding` → `runValuation`，一樣做 0 截斷與加權）。異常來自主模型沿用 CRWV 模板的 DCF 規則：
  - 常態化 FCF ≤ 0 時，DCF 判為「失效」，權重歸零，EV/EBITDA 改占 100%。
  - DCF 有效但股權為負時，DCF 腿以 0 計，仍占 45% 權重。
  - 利潤率一低到讓常態化 FCF ≤ 0，目標價就從「0 × 45%＋EV × 55%」跳成「EV × 100%」。結果是利潤率愈低、目標價反而愈高：穩態 EBITDA 率 45% 得 $105.3，47% 只有 $61.7。
- **修正**：「失效」只限 WACC ≤ g（Gordon 終值無定義）。常態化 FCF ≤ 0 時，終值以 0 計；DCF 照常走 0 截斷（或選擇權），保留 45% 權重。
  - 這與主模型對「DCF 為負仍保留權重」的既有理由一致：讓目標價反映「EBITDA 付不起資本成本」。
  - HTML（`segB.js` `dcfValue`）、Excel（評價_DCF與目標價「DCF 失效？（WACC ≤ g）」與終值公式）、cmp31 已同步修改。
- **MW 一律整數**：積極情境的輸入改為整數——併網速度 833.3333→833、合約上限 5,833.3333／6,666.6667→5,833／6,667、FY31 新增 833。積極情境已連網 MW 現為 750／1,583／2,416／3,249／4,082。HTML 表格的 MW 類欄位一律顯示整數、輸入框步進 1；Excel 的 MW 列原本就是 `#,##0`，另把季度追蹤「實際｜季末 connected power」由兩位小數改為 `#,##0`。
