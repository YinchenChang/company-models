## 改了什麼

### 第 0 步：工具檢查與補裝（工作階段內）
| 項目 | 原本狀態 | 處理 |
|---|---|---|
| `soffice --version` | 正常（24.2.7.2），但只有 LibreOffice 核心、沒有 Calc 模組，開 xlsx 會停住 | 補裝 `libreoffice-calc-nogui` |
| `openpyxl`、`playwright` | 可匯入 | 無 |

### 原始碼與文件
- **寫死路徑**：`build_xlsx.py`、`fix_outline.py`、`xlx.py`、`build_html_portable.py` 改為相對於 repo 根目錄。建置產物放 `out/`（`.gitignore`），HTML 模板預設用 `docs/template_v3_3.html`。
- **Python 3.11 相容**：`build_xlsx.py` 有一行 f-string 在內部重用引號（需要 3.12 以上），改成先存變數的等價寫法，輸出不變。
- **`scripts/recalc.py`**（新增）：用 LibreOffice headless 開啟、全部重算、原地存檔，輸出 JSON，並回報公式錯誤數（#REF!、#DIV/0!、#VALUE!、#NAME?、#N/A）。有錯誤或失敗時以代碼 1 結束。
  - 環境沒有設定 locale 時，中文檔名會變成 `??` 而停住，所以固定 `LC_ALL=C.UTF-8`，並以 file URL 傳遞路徑。
  - 逾時時終止整個程序群組。
- **`scripts/verify.sh`**（新增）：依序執行建 HTML → 建 Excel → 重算 → fix_outline → verify_ooxml → 三情境 xlx＋cmp31 → FY27 錨定 cmp31，任何一項失敗即以非零代碼結束。加 `--vs-dist` 時另外與 `dist/` 成品比對畫面文字、Excel 數值與公式。
- **`crawl.py` 修正**：原版只擷取第一個 `<main>`，而那只是資金模型頁的一個區塊。總結頁、損益與評價頁以及多數次級分頁的內容其實沒有被比對：把 `company.json` 的現價改成 90，舊版仍回報 0 差異。現在改為擷取整頁可見文字，並逐一展開兩層選單：
  - 修正前：22 個視圖、約 74k 字，其中多數是重複內容。
  - 修正後：32 個視圖、約 111k 字；同一個反例在 32 個視圖全部偵測到差異。
- **CLAUDE.md**：
  - 只有 `dist/` 成品改變時才升版並新增 VLOG；純工具修改不升版。
  - 每個任務結束時，把完整回報寫成 `docs/reports/YYYYMMDD_任務名稱.md`，隨 PR 一起提交（本檔為第一份）。
- **README、交接檔**：更新建置流程、執行環境需求、crawl 修正說明與 v3.6 補驗結果。
- 已合併 `main`（`docs/baseline_v3_6.html`）。
