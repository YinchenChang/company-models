# Nebius 引用的 Tokenomics 名稱（只限 IF_（不含 IF_Hdr*）與 L1_；工具：tools/tokenomics/import_tokenomics.py）
# 行尾 optional＝Tokenomics 尚未提供時快照記為 missing、不中斷（v5.26 起全部名稱皆已提供；v0.4a 新增名稱依 CoreWeave W9 用 optional 寫法）。
IF_RacksPerGW # 每 GW 機架數（每 MW GPU 數的核對）
IF_GPUsPerGW # 每 GW GPU 數
IF_FacilityGW # 每 IT GW 對應設施電力（MW 口徑換算）
IF_CapexIT # 每 GW 資本支出 — IT 設備
IF_CapexFacility # 每 GW 資本支出 — 廠房
IF_CapexTotal # 每 GW 資本支出 — 合計
IF_HoldAcct # 每 GW 年持有成本 — 會計口徑
IF_HoldEcon # 每 GW 年持有成本 — 經濟口徑
IF_GPUhrEcon # 每 GPU 小時持有成本 — 經濟
IF_PowerCost # 其中：每 GW 年電費
IF_Util # 基準利用率（第 0 層；token 服務口徑，m.util 對照）
L1_FacCapexMW            # 每 MW IT 廠房資本支出
L1_GPUhr_GB200_vsCW      # GB200 每 GPU 小時持有成本（對 CoreWeave 隨需牌價）
L1_GPUhr_GB300_vsBE      # GB300 每 GPU 小時持有成本（對新雲損益兩平租金）
L1_RevGW_Fleet_VR200     # 1 GW 參考機隊付費營收（理想上限，VR200）
IF_DeprLifeIT # IT 折舊年限（v5.26）
IF_DeprIT # IT 年折舊（v5.26）
IF_DeprFac # 廠房年折舊（v5.26）
IF_AvgDraw # 平均用電 ÷ 配電設計功率（v5.26）
IF_PowerPrice # 電價 $/kWh（v5.26）
IF_MaintIT # IT 維護（v5.26）
IF_MaintFac # 廠房維護（v5.26）
IF_StaffSW # 人員、軟體、水與耗材（v5.26）
IF_TaxIns # 財產稅與保險（v5.26）
IF_OpexGW # 營運費用小計，不含折舊（v5.26）
IF_RevGWFleet # 客戶每 GW 付費 token 營收（層級組合，理想上限；W4 上限檢查）
# v0.4a 新增（Tokenomics v18.0；比照 CoreWeave W9，optional 寫法）
IFW_RevGWFleet_100 optional # 客戶每 GW 付費 token 營收｜四層瀑布：理論上限（100% 利用；上限檢查）
IFW_RevGWFleet_Util optional # 四層｜扣技術利用率（＝IF_RevGWFleet；對照）
IFW_RevGWFleet_Prod optional # 四層｜再扣 SLO 下產能折減（上限檢查比較層）
IFW_RevGWFleet_Life optional # 四層｜壽命期等值（上限檢查）
IFC_Use optional # 上列各名稱的用途限制（「上限，不得作預測」；顯示於四層列旁）
L1_HoldEconMW_Hopper optional # Hopper 每 MW 經濟持有成本（L1；對照 IF_HoldEcon）
L1_HoldEconMW_GB200 optional # GB200 每 MW 經濟持有成本（L1；對照）
L1_HoldEconMW_GB300 optional # GB300 每 MW 經濟持有成本（L1；對照）
L1_HoldEconMW_VR200 optional # VR200 每 MW 經濟持有成本（L1；對照）
L1_TokMW_Gen_ratio_VR200 optional # VR200 對 GB300 每 MW token 產出比 q（基準；判讀）
L1_TokMW_Gen_ratio_VR200_Lo optional # q 低端
L1_TokMW_Gen_ratio_VR200_Hi optional # q 高端
# v0.5.1 新增（Tokenomics v19.0；比照 Oracle v0.3，optional 寫法）
L1_RevGW_PQ_VR200 optional # 模型商每 GW 實收營收 P×Q（v19.0；Nebius 每 MW 收入 ÷ 模型商實收的對照列，不設門檻）
L1_RevGW_PQ_VR200_Lo optional # P×Q 低端
L1_RevGW_PQ_VR200_Hi optional # P×Q 高端
