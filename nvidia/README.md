# nvidia/ — NVIDIA（NVDA）收支與估值模型 v0.1

NVIDIA 的營收＝加速器顆數 × 每顆售價＋網通附掛。2027 年 ASIC 把 NVIDIA 的金額份額壓到約 75–80%，HBM 漲價壓毛利 2–3 個百分點。股價取決於 2028 年顆數持平之後，EPS 還能不能成長：現價約為 2027 年 EPS 的 13.5 倍，是低估，還是見頂前的折價。

**核心問題：加速器顆數在 2028 年持平以後，NVIDIA 的 EPS 還能不能成長。**（命題的「2027 年」＝日曆年 2027＝FY2028；「2028 年顆數持平」＝CY2028＝FY2029，所以問題是 FY2030 EPS 相對 FY2029。）

AI 半導體 Project **運算層的第一個樣板**（之後 AVGO、AMD 複製）。獨立的 Python→Excel 產生器（比照 `advantest/`，openpyxl，LibreOffice 重算）。會計年度 FY(t)＝t−1 年 2 月～t 年 1 月，約等於日曆年 t−1（FY2027＝CY2026 … FY2030＝CY2029）；上游市場層是日曆年，FY(t) 直接取 CY(t−1)，**不做跨年加權**（11/12 落在同一日曆年，這是近似）。金額以十億美元為主。

## 驅動因子（全部唯讀上游）

| 驅動 | 來源 | 推導量 |
|---|---|---|
| 各世代顆數（Blackwell、Rubin、Rubin Ultra、Hopper）× 情境係數 | `markets/memory/market.py` 的 `UNITS`、`SCEN_UNITS`；與台積電、網通模型的同值建置時檢查 | 運算顆數 |
| 每顆售價（GPU 模組＋CPU＋LPDDR＋匣級加價中 NVIDIA 保留的部分） | `markets/chip_bridge` Rack 頁（GB300、VR200 模組價）；Rubin Ultra、Hopper 為 Assumed 區間 | 運算營收 |
| 網通附掛 | `markets/network` 的「NVIDIA 網通（本模型歸屬）」列（情境 B、C 依顆數係數縮放，網通與顆數成正比所以精確） | 網通營收 |
| HBM、LPDDR 成本與 NVIDIA 吸收比例 | `skhynix` 成品的情境別 HBM 單價、一般 DRAM 價格指數；橋接表 Rack 頁的吸收／轉嫁兩端 | 毛利率 |
| 中國資料中心運算 | 公司 Q3 FY2027 指引假設為 0；Sens 列「恢復」 | 營收 |
| Edge Computing、營業費用、稅率、股數 | 公司實績（Q 頁）＋ In 頁假設 | EPS |

- **EPS 口徑**：GAAP 扣除權益證券損益（一次性；Q1 FY27 $15.9B、Q2 FY27 $7.8B），含股票薪酬。公司自 Q1 FY27 起 non-GAAP 也含 SBC，Q 頁檢查列顯示兩者差 −0.03～−0.02。
- **FY2027 錨點**＝Q1、Q2 實績＋Q3 指引中點（$108.0B ±2%、毛利率 74.0%、營業費用約 $9.2B）＋Q4 假設（營收季增 10%、毛利率 71.5%、營業費用季增 8%）。錨點營收 404.6，較共識約 411.7 低 1.7%；錨點 EPS 9.06，較共識 9.31 低 2.7%（校準時未使用共識）。
- **毛利率**：非 HBM 成本占基準售價的比例（`c_nh`，Derived）在 FY2027 校準到錨點毛利率；FY2028 起的變化來自 HBM、LPDDR 成本、世代與顆數組合、吸收比例（`abs_mem`，Assumed 0–1，基準 0.5）。
- **不用營收反推顆數**：FY2027 由下而上的「顆數 × 每顆售價」與錨點不合，差額列在 Recon B 節；驅動因子從 FY2028 起作用。
- 公司 FY2028 指引（營收約 +70%、毛利率 72–73%）與共識只放在 Recon，不作校準。

## 估值（Val）

規則：FY2016–FY2025 年底 P/E 的分位（見頂 25 分位、中段中位數、谷底 75 分位）；循環位置用共用規則的 lag 版（`classify_lag`：FY(t) 對照日曆年 t−1），見頂年度讀設備市場模型（A 2029、B 2028、C 2027）。**擁有者 2026-10-23 核准的結果**：FY2028 在情境 A、B 為中段（中位數），情境 C 為見頂（25 分位）——Val 頁與 README 頁以公式／建置時計算驗證一致。另列對照欄：以本模型營收路徑自己的見頂年判斷（只作對照；情境 A、B 的營收到 FY2030 仍在增加，見頂年未知，標「截尾」）。

| 項目 | 數值 |
|---|---|
| 現價（2026-10-22 收盤，stockanalysis；10-23 收盤未找到） | $212.21 |
| 現價 ÷ FY2028 EPS（模型） | 12.0x |
| 現價 ÷ 共識 FY2028 EPS（15.91） | 13.3x（命題 13.5x 對得上共識，不是本模型） |
| 歷史年底 P/E 分位（Macrotrends，9 年） | 25 分位 42.1x、中位數 51.6x、75 分位 63.4x |
| 規則值：FY2028 EPS × 倍數（A／B／C） | $913（中段）／$914（中段）／$746（見頂） |

**規則值遠高於現價（+251% 至 +331%），不應當作目標價**：(1) 歷史倍數是落後倍數（年底價 ÷ 剛結束年度的 GAAP EPS），含高成長期溢價與 EPS 低谷年（FY2023 114.7x）；(2) 乘在 FY2028 EPS 上得到的是約 FY2028 年底的價格。Val 頁「What must be true」列：價格不變需要 12.0x，年報酬 10% 需要 14.5x，都遠低於歷史 25 分位。**本版沒有給出「低估」的結論**，只給出：現價隱含的倍數遠低於 NVIDIA 自己的歷史。

## 最大限制

- FY2027 由下而上水準差 +20.7%（Recon B 節）：基準按工作單不校準，FY2028 EPS 因此比共識高 11%、營收比指引高 20%；這是「顆數 × 橋接表售價」與公司實績之間的結構性缺口，不是參數微調能解的。
- 吸收比例（0.5）、匣級加價保留比例（0.5）、Rubin Ultra 售價（75K，60–100K）、各 ASIC 單價、Edge 與網通毛利率、營業費用彈性（0.6，由 FY2027 推得）皆為 Assumed 或兩點推導。
- 歷史 P/E 只有一個序列、落後倍數乘在未來 EPS 上；規則值只作對照。
- 情境 B、C 的網通縮放假設組合不變；情境係數（0.8／0.6）為 Assumed，無外部預測可校準。
- FY↔CY 不做跨年加權（近似）。
- 本模型不含 R4 產業部署路徑（`markets/deploy_path/` 尚未建立，Recon 預留列）。
