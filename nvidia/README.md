# nvidia/ — NVIDIA（NVDA）收支與估值模型 v0.2

NVIDIA 的營收＝加速器顆數 × 每顆售價＋網通附掛。2027 年 ASIC 把 NVIDIA 的金額份額壓到約 75–80%，HBM 漲價壓毛利 2–3 個百分點。股價取決於 2028 年顆數持平之後，EPS 還能不能成長：現價約為 2027 年 EPS 的 13.5 倍，是低估，還是見頂前的折價。

**核心問題：加速器顆數在 2028 年持平以後，NVIDIA 的 EPS 還能不能成長。**（命題的「2027 年」＝日曆年 2027＝FY2028；「2028 年顆數持平」＝CY2028＝FY2029，所以問題是 FY2030 EPS 相對 FY2029。）

AI 半導體 Project **運算層的第一個樣板**（之後 AVGO、AMD 複製）。獨立的 Python→Excel 產生器（比照 `advantest/`，openpyxl，LibreOffice 重算）。會計年度 FY(t)＝t−1 年 2 月～t 年 1 月，約等於日曆年 t−1（FY2027＝CY2026 … FY2030＝CY2029）；上游市場層是日曆年，FY(t) 直接取 CY(t−1)，**不做跨年加權**（11/12 落在同一日曆年，這是近似）。金額以十億美元為主。

## v0.1.1（PR 審查後）與 v0.1 的差別

1. **基準一致（k_rec）**：v0.1 的 FY2027 報告值用錨點、FY2028 起用未校準的由下而上，兩者水準差 20.7%，使 FY2028 營收年增達 +104%。v0.1.1 新增 **NVIDIA 認列顆數係數 k_rec**（Derived，只在 `nvidia/` 內縮放，不改 `markets/memory` 的共用顆數）：k_rec＝錨點 Data Center 營收 ÷ 未校準由下而上（市場層顆數 × 橋接表售價＋網通歸屬）＝0.828；營收與成本同比例縮放，FY2027 由下而上的 Data Center 營收與毛利率因此等於錨點（PL 頁核對列為 0），FY2028 起沿用。k_rec 以已發生的實績（FY2027 Q1、Q2 實績＋Q3 指引＋Q4 假設）校準，不使用公司對 FY2028 的預測（同 Disco v0.1.1 的作法）。顆數層與售價層無法分開識別，k_rec 是兩者的合併係數。
2. **pf_cal 保留當對照**：v0.1 的「只調售價」作法留在 Sens 頁當對照案例（k_rec＝1）。它的 FY2028 毛利率為 65.9%，與公司指引 72–73% 矛盾（Recon 頁列出）：只調售價時 HBM 成本相對營收被放大。
3. **Recon B2「差額來源待查」**：Rubin CY2026 出貨時點（FY↔CY）、B200／B300 價差等候選來源，各列附可查的公開資料與目前狀態。
4. **Val**：10 年落後 P/E 規則值標**不適用**（歷史倍數含高成長期溢價），保留計算但不進結論；結論改看現價 ÷ FY2028 EPS（模型與共識）。前瞻 P/E 歷史資料由擁有者另行提供，本版不做。
5. 維持：吸收比例 0.5、Rubin Ultra 60／75／100K、EPS 口徑。

- DCF：股東現金流＝EPS ×（1 − tp_g ÷ tp_roe），tp_r 10%、tp_g 4%、tp_roe 79.15%（valueinvesting.io GAAP ROE FY2024–FY2026 平均；再投資率約 5%）。FY2027 只計 2027-01 一個月（會計年度 FY2027 結束於 2027-01，基準日 2026 年底），FY2028 起逐年折現（t＝1/12 + k）。永續價值現值占 DCF 價值 66–77%。
- 延伸期：上游市場層只到 CY2029＝FY2030，**FY2031 起為收斂法，非驅動因子推導**（PL 頁末延伸表，橘底）：營收年增由 FY2030 線性收斂到 FY2032 的 tp_g±2pt，淨利率收斂到中段（C＝十年平均 31.18%，finboard／valueinvesting FY2016–FY2025 GAAP）。C 情境 FY2032 EPS 7.59（FY2030 11.43）。
- 情境對應：A＝順利（基準顆數）、B＝平平、C＝不如預期；FY2027 三情境相同、FY2028 幾乎相同，DCF 的情境差異主要來自 FY2029 之後。
- 本版未做先驗，無 Andy 合理 P/E 對照。舊的規則值目標價（v0.1.2）改名「舊法：規則值情境加權（參考）」保留在 Val 頁末。

**結論用（v0.1.1 起）**：現價 $210.96（2026-10-23 收盤）÷ FY2028 EPS＝**14.3x**（模型，情境 A；B、C 14.3x）、**13.3x**（共識 15.91）；命題的 13.5x 介於兩者之間。FY2029 EPS 的倍數（模型）：A 13.3x、B 15.9x、C 21.3x。Val 頁「What must be true」：FY2028 年底價格不變需要 14.3x，兩年 21% 報酬需要 17.3x。

**10 年落後 P/E 規則值：不適用**（保留計算，不進結論）。理由：歷史倍數是落後倍數（年底價 ÷ 剛結束年度的 GAAP EPS），含高成長期溢價與 EPS 低谷年（FY2023 114.7x）；歷史分位為 25 分位 42.1x、中位數 51.6x、75 分位 63.4x（Macrotrends，9 年，缺 FY2016），規則值 $620–761 是現價的 2.9–3.6 倍。前瞻 P/E 歷史資料由擁有者另行提供，本版不做。

循環位置：用共用規則的 lag 版（`classify_lag`：FY(t) 對照日曆年 t−1），見頂年度讀設備市場模型（A 2029、B 2028、C 2027）。**擁有者 2026-10-23 核准的結果**：FY2028 在情境 A、B 為中段，情境 C 為見頂；建置時以斷言驗證。另列對照欄（以本模型營收路徑自己的見頂年判斷，只作對照；情境 A、B 的營收到 FY2030 仍在增加，見頂年未知，標「截尾」）。

## 最大限制

- k_rec 假設 FY2027 的水準差在 FY2028 起持續（Recon B2 列各候選來源，皆未驗證）；若差額其實是 FY↔CY 出貨時點（暫時性），FY2028 起的營收與 EPS 會被低估。Sens 的 v0.1 未校準對照列給出上界（FY2028 EPS 17.69）。
- 吸收比例（0.5）、匣級加價保留比例（0.5）、Rubin Ultra 售價（75K，60–100K）、各 ASIC 單價、Edge 與網通毛利率、營業費用彈性（0.6，由 FY2027 推得）皆為 Assumed 或兩點推導。
- 毛利率路徑對吸收比例高度敏感（FY2028 −5.0 pt vs 公司指引約 −2.5 pt）。
- 歷史 P/E 只有一個序列、落後倍數；規則值不適用。
- 情境 B、C 的網通縮放假設組合不變；情境係數（0.8／0.6）為 Assumed，無外部預測可校準。
- FY↔CY 不做跨年加權（近似）。
- 本模型不含 R4 產業部署路徑（`markets/deploy_path/` 尚未建立，Recon 預留列）。
