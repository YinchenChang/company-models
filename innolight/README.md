## 重點觀察

1. 目標價 ¥1,355（DCF 831、Comparable 1,879 各半），比現價 612.63（2026-10-23）高 121.2%，級距 大於 50%；Comparable 單獨為 +206.7%。主因是倍數不是 EPS：本模型 12 個月後前瞻 EPS 41.68 比共識前瞻 EPS 75.09 低 44.5%，但 A 股光通訊同業（新易盛、天孚、光迅、華工、劍橋）前瞻 P/E 中位數 45.1 倍，現價只隱含 12.1 倍（共識未來 12 月 EPS）、共識目標價 1,321 隱含 17.6 倍；Comparable 未扣同業規模較小、部分價格日期較舊的溢價，也未計美國限制風險。DCF 單獨也有 +35.7%（ROE 30.6% 高於折現率 10%）。
2. 最敏感的是美國限制與份額：美國限制案例（份額相對值 2028 0.55）FY2028 EPS −39.1%、份額流失 −21.6%、降價快於模型 −19.4%、AI 市場 ×0.8 −19.1%；情境 C FY2028 EPS 29.17，比情境 A 的 49.78 低 41.4%，DCF 價格帶 498～1,049。
3. 追蹤 3Q26 季報（10-31 前）：FY2026 錨點的 2H26（季增 15%、毛利率 47%）為假設。CPO 份額對 EPS 影響小（份額 0 時 FY2028 −2.0%），但網通 CPO 目前只有一條路徑、三情境相同，CPO 替代可插拔的風險待 markets/network 改版。
