# samsung/ — 三星電子（005930.KS）收支與估值模型

記憶體樣板第三家（集團公司）。只建模記憶體事業（一般 DRAM、HBM、NAND）；手機、晶圓代工、面板、家電、Harman 以「非記憶體事業營收、營業利益」輸入；權益、淨現金、股數、估值為全公司。

**模型命題：** 三星電子 2026 年的獲利幾乎全部來自記憶體，盈餘由一般 DRAM 價格循環與 HBM 份額追趕兩條線決定；股價取決於循環見頂的年度、見頂時累積的淨值，以及非記憶體事業在谷底時能撐住多少。

## 最大限制

三星不揭露記憶體營業利益與 DRAM／NAND 拆分。基準年記憶體營業利益＝DS 營業利益＋晶圓代工與 LSI 虧損估計（每季約 2 兆）；DRAM 68% 依 TrendForce 推得。Q3 價格以 2026-10-08 初步財報（合併營收 195 兆）校準；Q3 合併營業利益模型 111.5 vs 初步 107.4（+3.8%）。

## 與共識的差距

2027 合併營業利益（A）比共識高 16%：共識隱含三星記憶體營益率約 75%，本模型約 82%。本模型沒有建入「三星利潤率結構性低於 SK 海力士」，因為成本結構未揭露；若改為 75%，2027 合併營業利益約 605 兆（共識 569）。
