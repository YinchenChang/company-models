## 重點觀察

1. 目標價 ₩477,143（DCF 486,542、Comparable 467,744 各半），比現價 215,500（2026-10-23）高 121.4%，級距 大於 50%；Comparable 單獨為 +117.1%。主因是倍數不是 EPS：本模型 2028 年底每股淨值 241,105 只比共識 232,055 高 3.9%（前瞻 EPS 78,917 比共識高 5.2%），但現價只隱含 0.89 倍前瞻 P/B，記憶體同業中位數 1.94 倍、共識目標價 478,906 隱含 2.06 倍；同業倍數未扣三星的集團折價，Comparable 偏高估。
2. DCF 情境價值 A 818,535、B 394,410、C 218,882（現價的 3.80／1.83／1.02 倍），對應 2028 EPS A 129,982、B 59,278、C 36,498；收斂期用的 ROE 為 2023–2025 平均 8.0%，低於折現率 10%，再投資率約五成，壓低 2030 年後的股東現金流。
3. 2028 B 營業利益對一般 DRAM 收入最敏感（±20% → ±15.2%），NAND ±30% → ±9.2%、HBM ±30% → ±7.3%；折現率 ±1pt 使加權目標價 −4.1%／+5.6%。下一個檢驗事件是 3Q26 確定財報與法說（約 2026-10-30，日期未確認；2026-10-08 初步財報已納入）。

## v0.3（2026-10-25）：目標價＝DCF 與 Comparable 加權；延伸到 2032（循環中段收斂）；現價更新；修正 2029 基期

## 與共識的差距

2027 合併營業利益（A）比共識高 16%：共識隱含三星記憶體營益率約 75%，本模型約 82%。本模型沒有建入「三星利潤率結構性低於 SK 海力士」，因為成本結構未揭露；若改為 75%，2027 合併營業利益約 605 兆（共識 569）。
