# 工作單 MAG v0.1b′｜移植：Alphabet、Microsoft 套用 Amazon 引擎（2026-10-08，r0，chat 端；兩家各執行一次）

- 前置：Amazon v0.1b 已完成並經 chat 端審查；該家 v0.1a 已完成並經審查。
- 必讀：共同規則、對照表 r1、Amazon v0.1b 報告的「移植說明」、該家 v0.1a 資料報告。
- 分支：`claude/<公司小寫>-v0.1`。先 `git fetch origin claude/amazon-v0.1`，從該分支**讀取**引擎檔複製到自己資料夾（`git checkout origin/claude/amazon-v0.1 -- amazon/<檔>` 到暫存處再搬，或 `git show` 輸出），**不得改 `amazon/`**。
- 本張改引擎與 `company.json`，不改 `dist/`、不升版。

## 步驟（每步：verify.sh → 進度檔 → commit → push）
0. 進度檔新增「v0.1b′」段落。
1. **複製引擎**：依移植說明，把 Amazon 的引擎與工具檔（seg*.js、tail.js、build_*.py、scripts/、Tokenomics 取數頁工具等）複製到自己資料夾，保留自己的 `data/`、`docs/`。
2. **company.json**：以 Amazon 的 `company.json` 結構為骨架，填入本家 v0.1a 資料：
   - **Alphabet**：日曆年、首期 0.5 年、期間 2026–2030；分部＝搜尋與其他、YouTube 廣告、聯播網、訂閱／平台／裝置、Other Bets（燒錢列，EBITDA 為負）；雲端＝Google Cloud（含 Workspace，註明拆分口徑）；自研 TPU 以 NonNV 比例換 VR 等值；Anthropic 持股；股利＋大額回購。
   - **Microsoft**：財年 6 月、首期 FY27 全年 1.0 年、期間 FY27–FY31、錨定 FY29（截至 2029-06）；分部＝M365 商用與消費、LinkedIn、Dynamics、Windows 與裝置、遊戲、搜尋廣告（依揭露細度，最多 6 線）；雲端＝Azure 及其他雲端服務（只有成長率時以 [Derived] 推絕對值）；租用 neocloud 算力以租金入營運費用；OpenAI 持股與營收分成（分成列對照）；股利＋回購。
3. **引擎差異**：若本家有 Amazon 引擎未涵蓋的機制，**先嘗試以 `company.json` 參數表達**；確實需要改引擎時，改在自己資料夾並於報告「引擎差異」一節逐項列出（之後由 chat 端決定是否回寫 Amazon）。
4. **verify 與回報**：同 Amazon v0.1b 第 11 步的報告內容（三情境、3 × 3 矩陣、AI ROIC 與打平 k、FCF 與回購、敏感度、已套用的預設、引擎差異）。
