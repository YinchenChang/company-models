## 一句話定位
中國大模型公司（模型層），以 GLM 系列模型為核心：過去靠替政府與企業「本地化部署」大模型賺錢，2026 年轉為以雲端 API 與 GLM Coding Plan 訂閱為主；算力向外購買服務，研發支出遠大於營收。

## 公司在做什麼
- 開放平台及 API（雲端部署）：開發者按 token 付費呼叫 GLM 模型；GLM Coding Plan（寫程式助手的月費方案）也歸在這一線 [本專案：zhipu/data/z1_raw/financials_notes.md §2]（[Derived]）。FY2025 Coding Plan 付費開發者約 24.2 萬人 [本專案：智譜收支模型_v0_1_1.xlsx SRC_ZP!D172]（[Interested-party]）。
- 本地化部署：把模型裝進客戶自己的機房，分為企業級智能體、企業級通用大模型、技術服務三線 [本專案：zhipu/data/z1_raw/financials_notes.md §2]。
- 國際站牌價：GLM-5.3 輸入 1.4、輸出 4.4 美元／百萬 token，Flash 版 0.15／0.5 [本專案：智譜收支模型_v0_1_1.xlsx SRC_ZP!D245、D247、D275、D277]；公司稱 1H26 API 平均售價上升 101% [本專案：智譜收支模型_v0_1_1.xlsx SRC_ZP!D231]（[Interested-party]）。
- 算力以購買服務為主：6/30 應付算力服務費 14.27 億元 [本專案：智譜收支模型_v0_1_1.xlsx SRC_ZP!D222]；公司稱國產晶片推論集群至少 10 萬顆 [本專案：智譜收支模型_v0_1_1.xlsx SRC_ZP!D233]（[Interested-party]）。
