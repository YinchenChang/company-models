## 一句話定位
中國大模型公司（模型層）：自研文字、語音、影片模型，一邊賣 API 給企業與開發者，一邊經營 Talkie／星野、海螺等消費型 App；算力主要向雲端租用，目前仍大幅虧損。

## 公司在做什麼
- 開放平台（API）：把 M 系列大模型以「每百萬 token 計價」賣給企業與開發者；M3 官方牌價輸入 0.30、輸出 1.20 美元／百萬 token [本專案：MiniMax收支模型_v0_2.xlsx SRC_MM!E60–E61]，2026-10-19 推出的 M3.1 Flash 降為 0.15／0.60 [本專案：MiniMax收支模型_v0_2.xlsx SRC_MM!E102–E103]。
- AI 原生產品（消費端）：AI 陪伴聊天 Talkie／星野（廣告＋訂閱）、影片生成海螺 Hailuo（訂閱）、語音 MiniMax Audio、MiniMax App [本專案：MiniMax收支模型_v0_2.xlsx SRC_MM!E15–E17]。
- 算力以租用為主：公司稱銷售成本主要是推論雲；與阿里雲的 2026 年採購上限約 300m 美元 [本專案：MiniMax收支模型_v0_2.xlsx SRC_MM!E63]（[Interested-party]）。1H26 物業設備＋預付款增至 341.1m，用途未說明 [本專案：MiniMax收支模型_v0_2.xlsx SRC_MM!E54]。
- 用量成長快但單價下滑：公司稱 2026-07 token 用量為 1 月的 20 倍；2026-08 ARR 超過 800m 美元、約八成來自企業端 [本專案：MiniMax收支模型_v0_2.xlsx SRC_MM!E57–E59]（[Interested-party]）。
