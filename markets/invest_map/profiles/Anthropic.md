## 一句話定位
AI 模型公司（位於 AI 金流的最上游）：自研 Claude 系列大模型，收入以企業與開發者按 token 付費的 API 為主（FY2025 82.6%，模型推估 FY2026 90.9%）[本專案：Anthropic收支模型_v0_1_5.xlsx SRC_ANT!E30、E5；Revenue!E58、E67；Derived]，算力向 Google、Amazon、Microsoft 等租用；本專案模型推估自由現金流 2029 年轉正 [本專案：Anthropic收支模型_v0_1_5.xlsx Funding!H14]，但前提是只計入已簽的算力合約。

## 公司在做什麼
- 模型與 API：Claude 分 Opus（頂層）、Sonnet（中層）、Haiku（低層）三個價位，按「每百萬 token」計價（token 是模型處理文字的最小單位）；2026-09 Opus 5.5 牌價輸入 4、輸出 20 美元，2026-10 Haiku 5.5 降至 0.1／0.5 美元 [本專案：Anthropic收支模型_v0_1_5.xlsx SRC_ANT!E115–E116、E119–E120]。
- 訂閱：個人 Pro 每月 20 美元、Max 100／200 美元，另有 Team 與 Enterprise 企業席位 [本專案：Anthropic收支模型_v0_1_5.xlsx SRC_ANT!E145、E147–E148、E150–E156]。
- 程式代理 Claude Code（讓 AI 直接讀寫程式碼的工具）：公司稱 2026-02 年化營收 2.5bn；第三方估 2026-05 約 8bn [本專案：Anthropic收支模型_v0_1_5.xlsx SRC_ANT!E62、E64]（[Interested-party]／[Analogy]）。本專案模型不另立營收線，併入訂閱與 API [本專案：anthropic/docs/handoff/Anthropic_handoff.md §4 D4]。
- 客戶以企業為主：2025-10 商業客戶約 300,000 家、企業與商業客戶約占營收 80%；2026-04 年化逾 1M 美元客戶約 1,000 家 [本專案：Anthropic收支模型_v0_1_5.xlsx SRC_ANT!E166、E40、E171]（[Interested-party]）。
- 營收規模：2025 年認列 4.6bn；2026 上半年 16.3bn、Q3 16.8bn [本專案：Anthropic收支模型_v0_1_5.xlsx SRC_ANT!E5、E384、E388]（外流招股書草稿與投資人簡報，[Interested-party]）。
