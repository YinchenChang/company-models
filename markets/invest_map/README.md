# markets/invest_map — AI 投資地圖

把算力收支（Tokenomics、雲端／neocloud／模型商模型）與 AI半導體（各公司模型、候選母體）的研究，放回 AI 供應鏈，呈現三個視角：

1. **供應鏈地圖**：每 1 GW 的資金流（Tokenomics 每 GW 資本支出、持有成本、P×Q 營收、回本比值）＋各層次產業與公司。
2. **產業地位**：研究覆蓋公司的地位分數排序。
3. **可投資性**：模型隱含價 ÷ 同日收盤價，分「機會／觀察／偏貴」。

## 檔案

| 檔案 | 內容 |
|---|---|
| `extract_models.py` | 從各公司 `dist/*.xlsx` 抽估值欄位，每值記錄檔案與儲存格 → `data/models_extract.json` |
| `data/tokenomics_snapshot_v*.json` | Tokenomics 官方取數快照（`tools/tokenomics/import_tokenomics.py`；名稱清單 `data/tokenomics_names.txt`） |
| `data/universe_ai_semis_v*.csv`、`data/segments_ai_semis_v*.csv` | AI半導體 候選母體與次產業排序的抄錄（權威在 AI半導體 Project Drive） |
| `data/prices.csv`、`data/prices_*_sources.md` | 同日收盤價與來源 |
| `build_xlsx.py` | 產生資料活頁簿 `dist/<日期>_AI投資地圖_資料_v*.xlsx`（**事實與判斷的權威位置**；黃底＝判斷輸入，重建時讀回） |
| `counter/Code.gs`、`counter/endpoint.txt` | 造訪計數器（Apps Script 原始碼；部署後網址） |
| `build_html.py`、`template.html` | LibreOffice 重算活頁簿 → 產生 `dist/index.html`（網站只呈現值，不計算）與 `dist/data.json` |

## 重建

```
python3 markets/invest_map/extract_models.py [--avgo <AVGO 成品 xlsx>]
python3 markets/invest_map/build_xlsx.py
python3 markets/invest_map/build_html.py
```

## 固定規格（2026-10-25，Andy 要求）

- 三個視角：供應鏈（依 AI 產業供應鏈）、個股產業地位排序、個股可投資性（考慮評價、估值與現價）。
- 風格：專業投資機構研究報告風格，不用休閒網站風格。
- 依據 Tokenomics：每 GW 金額只讀 Tokenomics 快照；公司估值只讀各公司模型成品。
- 可投資性一律用同一日收盤價；模型價日與比較日差距超過 20% 時標示「模型尚未反映期間變化」。**半導體個股自 v0.5 起改用模型現價**（見下條）。
- **個股數字引用模型，模型沒有的才自算**（Andy 2026-10-25 18:14）：原話「只要說是這個他們個股。模型有做的東西呢，你網站引用就直接引用，沒有的數字才自己算，基本上數字都是要引用個股模型的」→ 半導體個股的目標價、上檔空間、現價、投資建議、上檔空間級距一律讀模型 Val 頁；模型尚未補「投資建議／上檔空間級距」列者，依 AI半導體 固定規則（工作單 #164）以模型上檔空間自算並標示；悲觀情境空間（C 情境 DCF ÷ 模型現價 − 1；v0.5.1 前稱「下檔空間」）模型無此欄，自算。
- **不用「賣出」評等**（Andy 2026-10-26）：原話「我看到你那个频道里面有卖出，这跟放空会搞混，请取消或删除卖出这个平等」→ 全站只用五級：強力買進、買進、中立、放空、強力放空（另有收支不足、未估值、未上市）。雲端／neocloud／MAG 模型自身評等（含「賣出」與門檻句）不在網站顯示。
- **模型未更新時照樣評等**（Andy 2026-10-26）：原話「在模型还没更新之前，它既然都已经有了目标价，你就用他给的目标价与现在的价格……去计算出它的上档空间……然后依据我们的平等，去给他放他的一个评级」→ 雲端／neocloud／MAG：上檔空間（網站「中心空間」）＝模型加權目標價 ÷ 最近外部收盤價 − 1，依五級規則評等；價格偏離模型日逾 20% 仍標示「模型尚未反映期間變化」。收支關卡依下條（10-26 修訂）。
- **「下檔空間」改名「悲觀情境空間」**（Andy 2026-10-26：一般說的下檔空間是目標價相對現價會跌多少，原名易混）：＝C 情境（悲觀情境）DCF 價值 ÷ 模型現價 − 1（雲端取情境區間下緣與目標價較低者）。下檔價 → 悲觀情境價。
- **造訪計數器，不公開**（Andy 2026-10-26 10:46「加个拜访计数器。这个计数器不用公开出来，我自己看就好」；10:50 選自寫）：GitHub Pages 與 repo Traffic 不統計 Pages 網站造訪。網頁在開啟（view）、切換分頁（tab）、開公司檔案（profile）時送一筆到 Andy 自己的 Google Apps Script（`counter/Code.gs`，綁定 Drive `AI投資地圖/AI投資地圖_造訪紀錄` 試算表），寫入「紀錄」頁，「彙總」頁以公式統計每日開啟次數、不重複訪客、分頁與公司熱門度。網站上不顯示任何計數。不收 IP、不用 cookie；訪客代號為讀者瀏覽器內隨機值。網址存 `counter/endpoint.txt`（空白＝不計數；`build_html.py` 檢查格式）。網址加 `?nocount` 後該瀏覽器不再計數（Andy 自己的造訪可排除），`?count=on` 恢復。本機開檔（file://）不計數。
- 網站不做計算；判斷（分級門檻、權重、地位分項）只在活頁簿黃底欄修改。
- **數字只用本專案檢核過的資料**（Andy 2026-10-25 10:25）：網站上的數字只能出自算力收支或 AI半導體 的模型與比對檔；網路只用於新聞（近期重大事件）、管理層身分與即時股價。本專案沒有的數字寫「本專案未建立」。公司檔案規格見 `profiles/00_格式規格.md`。
- **公司檔案**（Andy 2026-10-25 10:22）：每家含管理層、市場定位與產業位置、在做什麼、主要產品與營收占比、同業與競爭、近期重大事件、需要觀察的事項；以右側面板分頁呈現，不整片攤開。
- **發布**（Andy 2026-10-25 10:24）：放 GitHub Pages（`gh-pages` 分支，`publish_pages.sh`），公司內可直接開啟；不再用 Streamlit。

- **收支關卡優先於評價**（Andy 2026-10-25 10:48）：原話「如果你的收支是入不敷出的，就是有資金缺口的，我们是不会平买进的……不要说那可投资性，那个评价看起来很低，上涨空间看起来很高，但它的现金流或它的收支都是负……这样是不行的。」→ 模型期間（2026 起約五年）現金收支合計 < 0 者，最終分級一律「收支不足」，不看估值空間。**10-26 修訂**（原話「如果它的本来的评价是买进，可是现金流会变成负的，那就是收支不足。但是它本来如果就是已经是放空或者强力放空了……最后的一个分级跟评价应该是保持的放空或强力放空，也就是它的现金流的不足，反而加重了放空它的一个原因」）→ 只有評價買進以上者改列「收支不足」；放空、強力放空維持；中立維持（[判斷] 預設，Andy 可改）；未估值者列收支不足。網站以「另：入不敷出」旁註。口徑：自由現金流列優先；雲端／neocloud 模板無此列者用「營運缺口（不含融資、不含還本）」；只有損益的半導體模型以各情境淨利皆為正判定（現金流本專案未建立，日後應補）。
- **公司檔案附完整收支模型**（Andy 2026-10-25 10:52）：GitHub Pages 的 `models/<資料夾>.html／.xlsx`；地圖圖例的「有模型」不得用分級顏色。

## 預設判斷（Andy 未回覆時照此；可改）

- 中心價（v0.4 起）：半導體讀估值 v2 模型的「目標價（DCF 與 Comparable 加權）」（AI半導體 2026-10-25：50% DCF＋50% Comparable，約 12 個月後；v2 模型已無「Andy 合理 P/E」列），下檔＝C 情境 DCF 價值（推到 12 個月後）；模型內「舊法：規則值情境加權價（參考）」放對照欄。雲端與 neocloud 用模型加權目標價；MiniMax 用反向檢驗折現價值。v0.3.2 以前：半導體 P/E 類取規則值與 Andy 合理 P/E 較低者。
- 個股範圍（v0.5）：AI半導體 全部個股模型（52 家，`extract_models.py` 的 `SEMIS_V2`）；公司名、次產業、重要性、地位依據取自候選母體，市場位置預設由次產業內優先序換算（[判斷]，黃底可改）。
- 新公司接入：v2 模型的目標價區塊列標籤統一（`extract_models.py` 的 `V2_*` 常數），新公司只要加進 `SEMIS_V2` 與 `build_xlsx.py` 的公司表即可；抽不到列會直接報錯，不會靜默略過。
- 分級：中心 ≥ +20% 且下檔 ≥ −25% → 機會；中心 < −10% → 偏貴；其餘 → 觀察。
- 地位分數＝0.40 × 不可替代性＋0.35 × 市場位置＋0.25 × 價值鏈分量。
