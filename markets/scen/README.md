# markets/scen — 市場層產業情境（A 順利／C 不如預期）

**版本：** v0.1（2026-11-05）　**擁有者：** AI半導體 市場層　**決策：** Siliconomics S41

## 為什麼在這裡

- Siliconomics v0.16 起只給基準（＝原情境 B；工作方式 v1.7「三層只給基準、情境在個股」）。原本放在 Siliconomics In 頁的 A、C 列（70 列）逐字搬到本資料夾，數值、標記、來源不變。
- B（基準）一律讀 Siliconomics 快照；本資料夾不另存 B 值（`scen.py` 載入時檢查不得重複持有）。
- 個股 A／C 預設讀本資料夾同字母情境（Andy 2026-10-25：各股情境與產業情境一致）。個股要覆寫時，須在該列說明欄寫明相對本資料夾的倍數，以及產業 GW 相對 Wattonomics 基準 ±%。
- 記憶體市場層 `markets/memory/market.py` 以 `scen.merged_rows()` 把 A／C 列插回原列序，記憶體公司 In 頁重播與 v0.15 逐列相同。
