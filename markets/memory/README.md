# markets/memory — 記憶體共用市場層

`market.py` 是所有記憶體公司模型（SK 海力士、美光、之後三星）共用的市場假設，由 `tools/memory_model/build.py` 寫進每家公司的活頁簿（Path、Mkt 兩頁，輸入在 In 頁 M1–M4 節）。

- **Path：** 一般 DRAM、NAND 合約價季增（2025Q2–2026Q4 取 TrendForce；2027Q1–2028Q4 依情境），算成季度指數；各公司依會計年度取平均。
- **情境：** A＝2027–28 高檔持平；B＝2027 Q2 見頂、2028 回落約一半；C＝2028 回到 2025 年價格水準。
- **Mkt：** 加速器顆數 × 每顆 HBM → 需求；MIN(需求, 供給) → 出貨；× 單價 → HBM 市場（日曆年）；對帳列（NVIDIA 由下而上 vs 營收推算、已發布市場規模）。

改這裡的假設＝同時改所有記憶體公司模型；改完要重建每一家並比對。
