# markets/memory — 記憶體共用市場層

`market.py` 是所有記憶體公司模型（SK 海力士、美光、之後三星）共用的市場假設，由 `tools/memory_model/build.py` 寫進每家公司的活頁簿（Path、Mkt 兩頁，輸入在 In 頁 M1–M4 節）。

- **Path：** 一般 DRAM、NAND 合約價季增（2025Q2–2026Q4 取 TrendForce；2027Q1–2028Q4 依情境），算成季度指數；各公司依會計年度取平均。
- **情境：** A＝2027–28 高檔持平；B＝2027 Q2 見頂、2028 回落約一半；C＝2028 回到 2025 年價格水準。
- **Mkt：** 加速器顆數 × 每顆 HBM × 情境顆數係數 → 需求；MIN(需求, 供給) → 出貨（每情境一列）；× 單價（依情境）→ HBM 市場（日曆年）；對帳列（NVIDIA 由下而上 vs 營收推算、已發布市場規模）。

## v0.4（2026-10-23）：HBM 位元隨情境

- **問題：** 之前只有單價隨情境，HBM 出貨位元三情境相同；台積電、Advantest 卻把情境係數乘在顆數上。
- **改法：** 情境顆數係數（2028 ×1.0／0.8／0.6、2029 ×1.0／0.85／0.6，[Assumed]；B、C 區間 ±0.1）放在 `market.py` 的 `SCEN_UNITS`（單一來源；`tsmc/build_tsmc.py` 改讀此處，值不變），輸入 `um28_*`／`um29_*`。需求位元＝情境 A 基準需求 × 係數；**供給三情境相同**（2028 產能 2027 前已訂定，需求下修的結果是閒置產能與降價）；出貨＝MIN(情境需求, 供給)；**單價假設不變**（價量同降，C 視為下緣）。
- **結果：** 出貨（EB）2028 A／B／C ＝ 8.50／8.22／6.17，2029 ＝ 11.48／11.36／8.02（原三情境皆 8.50、11.48）；HBM 市場 2028 B −3.3%、C −27.5%，2029 B −1.0%、C −30.1%。B 幾乎不變，因為 B 的需求只略低於供給。

**已決定（2026-10-23）：** (1) HBM 單價不隨新位元重估；**情境 C 的 HBM 市場（2028 97.2、2029 132.7 $B）為「價量同降的下緣」**——單價下修（−40%）與位元下修（×0.6）兩個下行假設相乘，不是中心估計；情境 B 同為價量同降，但位元幾乎不變。(2) 供給三情境維持相同。細節與下游前後差異見 `docs/reports/20261023_HBM情境與TK快照v20.1_報告.md`。

改這裡的假設＝同時改所有記憶體公司模型；改完要重建每一家並比對。
