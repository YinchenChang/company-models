## 最大限制

- 客供比例與保留毛利比例是 Assumed：公司只說「比重仍低」。
- 份額只有一個量化來源（經濟日報引述未具名美系券商、單月），且與有效份額口徑不同。
- 2028 年起每 GW ODM 價值（Rubin Ultra）是 Assumed。部署 GW 以 VR200 每 GW IT 資本支出換算，ASIC 機架每 GW 資本支出較低，GW 可能低估。
- 業外收益與稅前利益未找到，以淨利 ÷ 營業利益一個係數涵蓋；這是與券商差距最大的單一項目。
- 十年 P/E 兩來源 2016–2021 年相差約 3–6 個倍數點；2016–2022 年為筆電代工期的低倍數，規則值可能低估 AI 期的合理倍數。前瞻 P/E 歷史待 Bloomberg。
- 公司原文只經法說摘要與新聞；客戶占比（年報 10% 以上客戶）未找到。3Q26 法說（11 月中）後更新錨點。R4 產業部署路徑未建。
