# CoreWeave 引用的 Tokenomics 名稱（只限 IF_（不含 IF_Hdr*）與 L1_；工具：tools/tokenomics/import_tokenomics.py）
# 行尾 optional＝Tokenomics 尚未提供時快照記為 missing、不中斷（v5.26 起全部名稱皆已提供，無 optional）。
IF_RacksPerGW # 每 GW 機架數（每 MW GPU 數的核對）
IF_GPUsPerGW # 每 GW GPU 數
IF_FacilityGW # 每 IT GW 對應設施電力（MW 口徑換算）
IF_CapexIT # 每 GW 資本支出 — IT 設備
IF_CapexFacility # 每 GW 資本支出 — 廠房
IF_CapexTotal # 每 GW 資本支出 — 合計
IF_HoldAcct # 每 GW 年持有成本 — 會計口徑
IF_HoldEcon # 每 GW 年持有成本 — 經濟口徑
IF_GPUhrEcon # 每 GPU 小時持有成本 — 經濟
IF_PowerCost # 其中：每 GW 年電費
IF_Util # 基準利用率（第 0 層；token 服務口徑，m.util 對照）
L1_FacCapexMW            # 每 MW IT 廠房資本支出
L1_GPUhr_GB200_vsCW      # GB200 每 GPU 小時持有成本（對 CoreWeave 隨需牌價）
L1_GPUhr_GB300_vsBE      # GB300 每 GPU 小時持有成本（對新雲損益兩平租金）
L1_RevGW_Fleet_VR200     # 1 GW 參考機隊付費營收（理想上限，VR200）
IF_DeprLifeIT # IT 折舊年限（v5.26）
IF_DeprIT # IT 年折舊（v5.26）
IF_DeprFac # 廠房年折舊（v5.26）
IF_AvgDraw # 平均用電 ÷ 配電設計功率（v5.26）
IF_PowerPrice # 電價 $/kWh（v5.26）
IF_MaintIT # IT 維護（v5.26）
IF_MaintFac # 廠房維護（v5.26）
IF_StaffSW # 人員、軟體、水與耗材（v5.26）
IF_TaxIns # 財產稅與保險（v5.26）
IF_OpexGW # 營運費用小計，不含折舊（v5.26）
IF_RevGWFleet # 客戶每 GW 付費 token 營收（層級組合，理想上限；W4 上限檢查）
