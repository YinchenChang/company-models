## 改動
1. **DCF 失效（無法計算）時，DCF 腿以 0 計入原權重（45%）**，與「0 截斷」同口徑；不再改用 100% EV/EBITDA。理由：兩種狀態都代表 DCF 下權益價值不為正，現行口徑使目標價在兩狀態交界不連續、部分敏感度方向相反（W6 報告：k_長約 0.70、管銷率 GAAP 反而高於基準）。
   - Excel 公式與 JS 雙引擎同步；一頁摘要與評價頁顯示「DCF：失效（以 0 計入）」。
   - 反向 DCF、評等、區間、敏感度快照都依新口徑重算。
2. 其餘不動（每 MW 資本支出維持 Tokenomics、k 以單一倍數套用各世代，均為已決定事項 16）。
