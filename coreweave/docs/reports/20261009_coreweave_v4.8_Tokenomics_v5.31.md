# CoreWeave v4.8：接 Tokenomics v5.31（W6；v4.7 → v4.8）

2026-10-09｜工作單 W6（`docs/workorders/20261009_coreweave_W6_Tokenomics_v5.31.md`）｜PR #48｜Excel 版：`docs/reports/20261009_coreweave_v4.8_Tokenomics_v5.31.xlsx`｜成品：`dist/20261009_CoreWeave收支模型_v4_8.{html,xlsx}`

## 結論
1. **IT 維護改依機齡兩段後，模型首期營運成本與 CRWV Q2 實際一致**：Tokenomics 1.33 對 Q2 實際 1.36（+2%，v4.7 為 −35%）→ 規則 1，W5 留下的「營運成本」待決項消失。原因：Q2 季末 93% 機隊仍在 3 年保固期內，v4.7 卻按滿載維護費率計算。基準每 MW IT 維護 FY26–FY30 由 0.94–1.08 降為 0.18–0.50（隨機隊老化上升）。
2. **GB300 機架價格下修使每 MW 資本支出由 34.8 降為 30.6**，對 1H26 實際 24.8 的差距 −29% → −19%，仍 > 10% 且找不到機制 → 維持 Tokenomics（規則 3）。但同一變動也使 Tokenomics 持有成本（收入的錨）下降；k 不動時新合約收入跟著下降，抵銷約一半的成本利益。
3. **加權目標價：保守 $29.32、基準 $18.53、積極 $0.00，三者仍皆賣出**（v4.7：$18.44／$13.29／$0.00）；融資缺口 51.0／100.9／179.6 → 40.7／89.4／165.4。FY26 模型對 Q2 實際：收入、營運成本、租金、管銷、EBITDA 都在 ±3% 內（EBITDA 率 58.4% 對 58.6%）。
4. **MW 口徑**：10-K FY2025 與 10-Q Q2 2026 原文都沒有定義「active／contracted power」→ 依工作單維持 IT，不改。

## 需要 Andy 決定的事項（逐項附建議）
1. **k_長約 是否隨 v5.31 重算**：k_長約 0.76＝IREN–Microsoft 9.70 ÷ GB300 持有成本 12.72（v5.27）。v5.31 持有成本降為 10.89 後，同一筆證據的倍數是 0.89（「k 證據表」已自動更新）。工作單規定收入口徑不動，所以 v4.8 維持 0.76，等於假設新合約價格比 IREN 低 15%。改為 0.89：基準 $18.53 → $31.40（敏感度「k_長約 0.89」）。**建議另開工作單改為依證據重算（0.89）**：k 的定義是「市場價格 ÷ 同世代 Tokenomics 持有成本」，持有成本改了、價格沒變，倍數應跟著改；既有合約 k_既有 也已升到 0.91。
2. **每 MW 資本支出**（Tokenomics 30.6 對 1H26 實際 24.8，−19%，找不到機制）：維持 Tokenomics（$18.53）或改用 1H26 實際比率 × 0.81（$30.01）。**建議維持**，Q3 10-Q（11 月）再比一次。
3. **DCF「失效」與「0 截斷」的不連續**：DCF 失效（常態化 FCF ≤ 0）時權重歸零、目標價＝100% EV/EBITDA 腿；DCF 有效但股權為負時 0 截斷、目標價＝55% × EV/EBITDA 腿。v4.8 基準由「失效」變成「0 截斷」，所以 EV/EBITDA 腿 +$20.4 只反映 +$5.2；也使部分敏感度方向相反（k_長約 0.70 $23.15、管銷率 GAAP $22.72 都高於基準 $18.53，因為這些設定下 DCF 失效）。選項：(a) 維持；(b) 失效時也以 0 計入 45% 權重（與 0 截斷一致，目標價只會更低或不變）；(c) DCF ≤ 0 時一律 100% EV/EBITDA。**建議 (b)**（單調、保守）；屬評價口徑，需另開工作單。
4. **2023 年底主動電力**：10-K 原文寫 2023 年底「approximately 70 MW」，模型 `defaults.mwYearEnd` 2023＝100。影響 FY29 汰換批次（100 對 70 MW）與 2023 年機齡層。**建議 chat 端核對後另開工作單修正**（本單未改）。
