## 結論
1. **口徑**：DCF 失效（WACC ≤ g 或常態化 FCF ≤ 0）時，DCF 腿以 $0 計入原權重 45%，與「股權為負 → 0 截斷」同口徑；不再改用 100% EV/EBITDA。失效時一頁摘要結論句末加「DCF：失效（以 0 計入）。」，評價頁 DCF 權重說明、計算式、DCF 每股列顯示同樣字樣。
2. **三情境目標價不變**：保守 $42.70、基準 $31.99、積極 $14.72（皆賣出；三情境 DCF 皆 0 截斷、不是失效）。融資缺口、評等、情境區間、方法區間、反向 DCF 都不變。變動拆解 (a)(b)(c)(d) 全為 0（方法變更 (d) 只影響失效狀態；`scripts/attrib.py --base v4.8 成品 --d v4.9 成品`：三情境兩條腿與加權目標價皆 +0.00，檢查通過）。
3. **改變的只有 DCF 失效的敏感度組合**（共 5 格，見第 2 節）：例如保守 × Tokenomics 高成本 $18.06 → $9.93（＝55% × EV/EBITDA 腿 $18.06）。
4. **單調性**：舊口徑有 2 個敏感度方向相反（較差的假設反而得到較高目標價），新口徑 0 個；建置成本倍數掃描，舊口徑在失效交界跳升（保守 $16.03 → $27.20、基準 $13.19 → $22.39），新口徑三情境都單調遞減。
