# micron/ — 美光（MU）收支與估值模型

記憶體樣板 v0.2 的複製測試（第二家；之後三星）。

**模型命題：** 美光的盈餘由一般 DRAM 與 NAND 的合約價循環決定，HBM 份額約與其 DRAM 份額相當（約兩成）；股價取決於循環見頂的年度與見頂時累積的淨值，以及「超額現金 100% 回饋」把淨值轉成買回的速度。

| 檔案 | 內容 |
|---|---|
| `company.py` | 設定檔（只放參數） |
| `dist/20261008_美光模型_v0.1.xlsx` | 成品（LibreOffice 重算，錯誤 0 格） |

建置：`python3 tools/memory_model/build.py micron/company.py raw.xlsx`，再以 LibreOffice headless 重算。

## 複製測試結果

- 美光本身只需要設定檔，沒有改樣板結構。
- 但為了美光，樣板先升級為 v0.2：會計年度（9 月初結束，FY27 ≈ 2026Q4–2027Q3）、幣別（美元）、價格改為共用季度路徑依會計年度平均。SK 海力士同步以 v0.2 重建。
- 樣板限制：預測只到基準年＋2 年；美光會計年度落後日曆年一季，情境 C 的完整谷底落在 FY29，超出範圍。
