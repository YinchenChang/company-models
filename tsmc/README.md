# tsmc/ — 台積電（2330.TW）供給上限與收支估值模型

AI 半導體 Project 步驟 4。獨立的 Python→Excel 產生器（不套記憶體樣板；損益與估值結構比照）。

**模型命題：** 台積電是 AI 加速器的供給上限之一。用加速器數量層（`markets/memory/market.py` 的 `UNITS`）推算 CoWoS 片數需求，與台積電＋委外產能對帳，判斷 2027 年瓶頸在 CoWoS 還是 HBM；AI 營收＝加速器數 × 每顆台積電內容 × 價格調升，非 AI 另行成長；P/E 估值。

| 檔案 | 內容 |
|---|---|
| `build_tsmc.py` | 產生器（參數與公式） |
| `dist/20261022_台積電模型_v0.2.xlsx` | 成品（LibreOffice 重算，錯誤 0 格） |

工作表：README、In、CoWoS、PL、Val、Recon、Sens、Sources。情境 A／B／C：2028–29 加速器數 × 1.0／0.8–0.85／0.6，毛利率路徑分開。

## 最大限制

- 每片封裝數與每顆台積電內容為 Derived／Analogy（36Kr、Silicon Analysts、橋接表 v0.1），未經公司揭露。
- CoWoS 年底月產能來源分歧：KGI 2027 年底 170k（本模型 200k）；改用 170k 時 2027 需求 ÷ 產能 106%，CoWoS 變成與 HBM 同時受限。
- 加速器數量 2026–28 取自市場層；未接 Tokenomics 具名範圍（待 R1/R2）。
