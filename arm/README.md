# arm/ — Arm Holdings（ARM）個股模型 v0.1

Arm 的權利金＝各市場晶片出貨 × 每顆權利金率：智慧型手機（出貨持平到下滑，成長靠 v9 與 CSS 費率）、資料中心 Neoverse（NVIDIA Grace／Vera 顆數讀 Siliconomics 加速器顆數、雲端自研 CPU 年增、每顆費率隨核心數上升）、車用、物聯網與其他；授權及其他＝授權（含 SoftBank 協議）＋自研 Arm AGI CPU 晶片。

**核心問題：現價約 95 倍共識前瞻 EPS，市場是否已把資料中心權利金倍增、CSS 費率上升與自研晶片（客戶需求逾 20 億美元）全部算進去；Qualcomm 判決與手機出貨下修會讓權利金少多少。**

**投資建議：強力放空**（依上檔空間固定規則：加權目標價上檔空間 −76.6%，小於 −50%）。

> **待 FQ2 財報：** 2Q27（2026-07～09）財報 2026-11-04 美東盤後公布；本版 FY2027 錨點＝1Q27 實績＋2Q27 公司指引＋下半年假設。

## 重點觀察

1. 目標價 US$53.52（DCF 34.56、Comparable 72.48 各半），比現價 228.88（2026-10-30）低 76.6%，級距小於 −50%、投資建議強力放空；Comparable 單獨為 −68.3%。差距全部來自倍數：本模型 12 個月後前瞻 EPS 2.90 反而比共識前瞻 EPS 高 20.1%（期間晚約一年），但現價約 94.7 倍共識前瞻 EPS、共識目標價 290.71 隱含 120.3 倍，同業前瞻 P/E 中位數只有 25.0 倍。DCF 偏低另因 GAAP ROE 近三年平均 10.5%（再投資率 38%）。SoftBank 持股約九成，流通市值約 247 億美元（總市值 2,472 億），流通量低可能撐住溢價，本模型不調整；ARM 無 Bloomberg 前瞻倍數，相對倍數係數＝1。
2. 單一參數都翻不過來：最有利的單一案例是 DCF 權重 0.3（+14.2%），其次授權成長 15%（+6.8%）、營業費用年增 8%（+7.4%），目標價仍比現價低七成以上；授權成長 2% −10.3%、營業費用年增 18% −7.7%、晶片毛利率 35%／55% ±4.6%（Sens 頁）。
3. 可追蹤的三件事：資料中心占權利金由 FY2026 14% 升到 FY2029 情境 B 24.9%（Grace／Vera 讀 Siliconomics、雲端自研 CPU 年增 30%）；AGI CPU 晶片營收 FY2028 情境 A／B／C＝14／10／5 億美元，對照公司稱 FY2027–28 客戶需求逾 20 億美元；Qualcomm 陪審團 2026-10-13 判 Arm 違約，法官審理部分待判。下一個檢驗點：2Q27 財報 2026-11-04（指引營收 13.8 億美元、non-GAAP EPS 0.47）。

AI 半導體 Project 運算次產業（CPU 架構 IP）。樣板 `crdo/`（美股、估值 v2），敏感度與上游讀法比照 `tuc/`。金額十億美元；EPS 為 non-GAAP（公司與共識口徑，排除股票薪酬與併購攤銷；GAAP EPS 另列於 Q 頁）。

**會計年度對照：** FY(t) 於 t 年 3 月 31 日結束（FY2027＝2026-04～2027-03）。上游市場層是日曆年，FY(t) 市場＝9/12 × CY(t−1)＋3/12 × CY(t)；Siliconomics 顆數情境係數（CY2028 起）因此只有 3/12 進 FY2028，B、C 的差異主要在 FY2029。

## 營收分部

- **官方：** 公司為單一營運部門，營收依類型揭露兩類：授權及其他（License and other）、權利金（Royalty）。FY2025 18.39／21.68、FY2026 23.07／26.13 億美元；最近四季（2Q26～1Q27）授權 5.15／5.05／8.19／5.74、權利金 6.20／7.37／6.71／7.15 億美元，四季合計與年度、季報一致（Q 頁；2Q26 由全年減其他三季）。
- **權利金子列（命題）：** 智慧型手機（20-F：約 43%，Verified）、資料中心（管理層「十幾到接近 20%」，取 14%）、車用（9%，Assumed）、物聯網與其他（殘差）；FY2025 沿用 FY2026 比例。
- **授權及其他子列：** 授權（含 SoftBank 協議，3Q26 約 2 億美元／季）＋Arm AGI CPU 晶片（公司未揭露所在列，暫列於此，Assumed）。

## 估值（Val 第 0 節）

**目標價（DCF 與 Comparable 加權，各 50%）：US$53.52，上檔空間 −76.6%（級距小於 −50%，強力放空）。** Comparable 目標價（市場主流同業法）US$72.48（−68.3%）；相對倍數係數 1.00（ARM 無 Bloomberg 前瞻倍數，待取；Synopsys、Cadence 也不在 csv）。DCF 目標價 US$34.56（12 個月後情境價值 A 46.47、B 32.83、C 21.01；r 10%、g 4%、ROE 近三年平均 10.5%，GAAP）。同業前瞻 P/E：高通 19.5x、博通 18.5x、邁威爾 43.0x、Rambus 24.2x、新思 25.7x、益華 36.0x；中位數 25.0x × 12 個月後前瞻 EPS 2.90（5／12 × FY2028＋7／12 × FY2029）。市場共識目標價 US$290.71（43 位，S&P Global，2026-10-21）；差距拆解：EPS 因素 +20.1%、倍數因素 +381.7%（共識目標價隱含 120.3x）。歷史倍數檢查：現價 ÷ FY2028 EPS 81.6–97.2x，高於 2023–2025 年底 P/E（59–76x），三情境皆 100%（只作檢查）。

現價 US$228.88（2026-10-30 收盤，InvestSmart；digrin 228.77；其他模型仍用 10-22／10-23 收盤）÷ FY2026 EPS＝129.4x；÷ FY2027＝107.8x；÷ 共識前瞻 EPS＝94.7x。SoftBank 持股約九成，流通市值約 247 億美元：流通量低與指數權重限制可能讓溢價持續，Comparable 法等於假設溢價在 12 個月內消失（偏低估）；本模型只在方法說明，不作調整。本版未做先驗，無 Andy 合理 P/E 對照。**Bloomberg 前瞻倍數待取。**

## Arm 自研晶片、Qualcomm、SoftBank

- **AGI CPU：** 2026-03 推出，首批已交付美、中客戶；客戶需求 FY2027–28 逾 20 億美元，已取得 10 億美元的產能；公司稱朝此業務 150 億美元的預估前進。模型以情境 A／B／C 的晶片營收與 45% 毛利率處理（Assumed），晶片毛利率遠低於 IP，晶片占比上升使毛利率由 98% 降到 FY2029 B 86%。
- **Qualcomm：** 2026-10-13 陪審團判 Arm 違反架構授權並干擾 Qualcomm 與 Meta 的關係；法官審理部分 10-20 結辯、判決未出，損害賠償未揭露。模型：情境 C 手機費率年增 7%，另以 `qc_adj`（−6%～+2%）作敏感度。
- **SoftBank：** 控股股東（20-F），持股約九成（媒體）；SoftBank 協議認列在授權及其他（約 2 億美元／季），期間與續約未找到。

## 最大限制

- 公司只揭露手機占權利金比例，資料中心、車用、物聯網拆分為 Assumed（管理層口頭說法）。
- AGI CPU 晶片營收所在列、認列時點與毛利率未揭露；晶片營收三情境皆 Assumed。
- non-GAAP EPS 排除股票薪酬；DCF 以 non-GAAP EPS 搭配 GAAP ROE，口徑不一（偏誤方向相反，見 Val 方法列）。
- 年底 P/E 只有 2023–2025 三年；FY2028 共識未找到。
