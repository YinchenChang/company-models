# 「2027 起不計 Blackwell」重審（2026-11-18；第二波 Wattonomics 報告 A）

**性質：** 只算、不改模型。情境建置都在 /tmp，未提交。基準＝main 的 Wattonomics v0.3.6（Siliconomics 快照固定 v0.19）。

## 結論

1. **這個假設來自 v0.1 工作單的簡化，不是證據。** 位置：`wattonomics/builder/build.py` 第 694–702 行（Players 頁世代占比公式：2027–2029 只給 VR200 與 Rubin Ultra，其他世代寫死 0），第 714 行註記「2027 Blackwell 2.4M 顆不計（工作單：2027 起 VR200）」；來源是 `wattonomics/docs/workorders/20261028_Wattonomics_v0.1.md` 第 32 行「2027 起 VR200」與 Decisions GL01-11。In 頁 `mix_*` 標記寫「Derived（2026–29）」，但 2027 的 Blackwell＝0 是寫死的常數，**實際等級是 [Assumed]（無依據）**，標記不準確。
2. **把 Blackwell 加回 2027，Wattonomics 的 NVIDIA 實體 GW 幾乎不變：** 15.34 → 15.53（基準）→ 15.65（高），最多 +0.31 GW；兩層 2027 NVIDIA 差距 13.31 → 13.12 → 13.00，只縮小 1.4%–2.3%。**「不計 Blackwell」不是 2027 年 14–15 GW 差距的原因。**
3. 原因：Wattonomics 的 GW 是「資本支出 ÷ 每 GW 成本」，世代組合只透過每 GW 成本影響總量（GB300 每 IT GW IT capex 32.24 對 VR200 37.59，廠房相同 12.67），而且只影響由資本支出推得的七家與 xAI。它主要改的是**平台拆分與顆數**：Wattonomics 隱含封裝數 438 萬 → 475 萬 → 498 萬（Siliconomics 912 萬）。R1R2 報告的「Blackwell 差 4.63 GW」大部分是拆分口徑造成的，總量差距要在資本支出總額與買方覆蓋找。
4. NVIDIA 2027 對帳比（隱含 ÷ 指引推得）0.645 → 0.649 → 0.651：「只有公司指引推得值的 47%–77%」也不是這個假設造成的。
