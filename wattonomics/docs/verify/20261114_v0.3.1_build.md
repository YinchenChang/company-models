## 待判斷

1. **證據比例要不要去重**（GL01-86）。
   - 工作單寫的是「站點證據＋七家實績」直接相加。
   - 但七家的站點和資本支出實績是同一批 GW，直接相加會重複計算：2026 年字面算法得到 1.0（被上限截住），2027 年得到 0.631。
   - 我採用的是「逐家取兩者中較大的那個」，字面算法另列作對照。**這個選擇會影響 2027 年的狀態**：去重後是 0.492，屬丙；字面算法是 0.631，屬乙。
2. **2027 年的證據比例 0.492 很接近 50% 門檻。** Siliconomics 拿到 NVIDIA FY27Q3（11-19）實績、以及 Z1 核對完成後，可能需要重判；重判時依規則 v1.1 的緩衝區處理。
3. **工作單寫的「W1＋W2 調整後比值」**：我依 Siliconomics r4_bridge 第 p5 列，把它讀成「④＋W2」。如果 W1 另有所指，請告訴我。
4. **2030 年的 ④ 和 W2 延續 2029 年的值**（`gap_carry30`＝1）。這兩項原本只量到 2029 年。
5. **SIL_In 仍讀幾個不是 `*_Base` 的名稱**：平台顆數、每顆 IT capex、vr26、nv_content、ITCapexPerGW。
   - 它們只用在比例與單價，S33 係數同乘時不影響比例。
   - 如果改讀別的名稱，基準 GW 會變，所以本版沒有改。
6. **Siliconomics 的證據比例目前是 In 手輸入**（`sil_ev_*`，取自 AI半導體 橋接表）。Siliconomics 自己量出來之後，再改成讀它的快照。
7. **Microsoft 的公司口徑資本支出**：FY27Q1 的 45.2 只有轉述來源；而且公司口徑不等於「現金 PP&E＋融資租賃」，Z1 B1 也記為未查明。目前證據比例用 118.1（Q1–Q3 公司口徑）。
