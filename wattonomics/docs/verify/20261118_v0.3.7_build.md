## 3. C4a：做了什麼

2027 的區間來自分子計法（低＝只計站點；高＝站點＋七家實績全額；基準＝逐家取大者）。2028 起七家實績支撐為 0，三種分子相同，區間塌縮成一點，該法不適用。改為只在 2028、2029 動分母裡的 ④ 覆蓋缺口，端點取 Compare H1 既有的「④ 實績下限讀法」低／高（0.06／5.91 GW，基準 1.58）：

- 低＝基準分子 ÷（主路徑＋④ 高＋W2）
- 高＝字面讀法分子 ÷（主路徑＋④ 低＋W2）

新增 Compare H2 兩列 `evden_lo`、`evden_hi`；`evlo`、`evlit` 只有 2028、2029 改讀它們。等級 [Assumed]：端點依據只有 H1 兩讀法自身的低／高，沒有外部觀察值。Decisions GL01-123。
