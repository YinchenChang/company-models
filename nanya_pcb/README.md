ABF 營收＝MIN（需求, 產能）。需求由三部分組成：

**與共識的差距（超過 30% 的原因）**：

- **FY2027 EPS 33.05（A）**：比 FactSet 平均 32.12（2026-06）高 3%，比美銀 43.80、凱基 38.88 的平均 41.34 低 20%。
- **FY2028 EPS（A）35.90**：比 FactSet 平均 59.21 低 39%，比美銀、凱基平均 65.72 低 45%。

主要原因有三個：

1. 每顆載板的價格溢價沿用 Ibiden 模型：2027 年持平，2028–29 年回落到 0.95／0.90。券商假設 ABF 單價持續上漲（研究報告：2027 年每平方呎 +57%），美銀估 FY2028 毛利率 46.6%，本模型 35.2%。溢價取 Ibiden 高值（1.05／1.05／1.00）時，FY2028 EPS +18%。
2. ABF 產能指數使 FY2027–28 營收受限，需求滿足率約 95%。凱基估新產能 2029 年才到位。
3. 沒有建入美銀提到的 AMD 伺服器 CPU 新業務：認證成功時，2027 年可逾營收兩成。

FY2028 營收 888 億，比 FactSet 平均 1,335 億低 34%。FY2027 營收 802 億，比 FactSet 低 11%。

**DCF 的設定**：

- v0.3 起為標準版 FCFF＋WACC（見上方 v0.3 一節）；以下為 v0.1–v0.2.1 的股東現金流法說明（每股（淨利＋折舊－資本支出），r 10%、g 4%），數字為當時撰寫。
- 股東現金流＝每股（淨利＋折舊－資本支出）。模型有資本支出與折舊，所以不用 EPS ×（1 − g／ROE）。
- 參數：r 10%、g 4%。
- 期間：FY2027–32 明確期，加上永續價值。
- 情境價值低於 0 時取 0；本版三情境都是正值。

DCF 低於 Comparable 有兩個原因：

- 明確期的 EPS 在 FY2028 起成長放緩：溢價回落、產能受限。
- 永續成長只有 4%。

參考：EPS ×（1 − g／ROE）法的 DCF 目標價為 137。近三年 ROE 5.4%，所以再投資率 74%。

**Comparable 偏高**：同業同處 ABF 短缺溢價期；三星電機的價格是 8 月的。

**十年 P/E 規則值**（第 3 節）只作參考，不是目標價：

- 年數：2016–2018 年虧損不計，用 2019–2025 共 7 年。
- 規則倍數：中位數 34.9x（A、B 判為中段）；C 的營收最高年是 FY2027，判為見頂，取 25 分位 29.0x。

## 最大限制

- 加速器、交換器與 CPU 載板的拆分，公司沒有揭露；其他 AI 載板是校準殘差。ABF／BT 的年度占比取自券商與法說摘要（區間）。
- 份額、產能指數、漲價年度化都是 Assumed；與 Ibiden、欣興的份額合計只做上限檢查。
- 毛利只用現金流通率近似，沒有建分廠稼動率與昆山爬坡良率。
- 新廠資本支出未定（公司待董事會決議），DCF 現金流可能偏高。
