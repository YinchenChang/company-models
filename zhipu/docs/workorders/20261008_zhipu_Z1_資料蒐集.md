## 每筆格式（YAML list）
```yaml
- key: rev_api_1h26            # 小寫英文 slug，唯一
  group: A                     # 規格第 4 節的分組字母
  metric: 開放平台及 API 收入    # 繁體中文
  value: 8.25                  # 數值；只有區間時 value 留 null
  lo: null
  hi: null
  unit: RMB 億                 # 金額一律註明幣別；原文幣別照錄，不自行換匯
  period: 1H2026               # FY2025、1H2026、2026-07、時點日期
  source: 智譜 2026 中期業績公告
  url: https://www1.hkexnews.hk/...
  doc_date: 2026-08-xx
  retrieved: 2026-10-08
  tag: Verified                # Verified／Interested-party／Analogy／Assumed／Derived
  party: null                  # Interested-party 必填：利害方與誘因
  basis: null                  # GW 類：IT／設施／未明；金額類：經審計／未經審計（已審閱）／管理層口徑
  note: 原文摘錄（≤40 字）與口徑說明
```
- 同一事實多個來源互相矛盾：全部登錄（key 加後綴 `_b`、`_c`），note 寫矛盾點。
- 找不到：另列 `not_found:` 區段（項目、試過的來源與查詢詞、判斷是「找不到」還是「可能不存在／未揭露」）。
- 不得杜撰；不得用模型記憶補數字——每筆必須有可開啟的網址與原文摘錄。SemiAnalysis 不可單獨引用。

## 判斷類預設
| 問題 | 預設 |
|---|---|
| 經審計財報科目 | Verified（note 寫審計師與報告日） |
| 中期報告（未經審計） | Verified（basis 寫「未經審計（已審閱）」） |
| 公司自述（業績會、新聞稿、高層訪談、「10 萬級」「40 倍」等倍數） | Interested-party（智譜：上市後股價、配售、招募誘因） |
| 媒體引述「知情人士」 | Interested-party（媒體名列入 source） |
| 第三方量測（卡時租價、App 月活、OpenRouter 份額） | Analogy（給區間；說明與智譜全體的差異） |
| 券商報告、共識 | Interested-party（券商：承銷、交易誘因） |
| 合作方公告（雲廠商、晶片廠、地方算力平台） | Interested-party（合作方宣傳誘因） |
