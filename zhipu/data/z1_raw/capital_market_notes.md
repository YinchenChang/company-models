## 四、併購

- **北京紅鑽（100%）**：董事會 2026-03-31 決議、2026-04-14 公告；總代價上限 RMB 360.52 百萬（股權現金 RMB 81.62 百萬，加上債務安排約 RMB 278.9 百萬），全部付現。標的是海淀中關村軟體園鑽石大廈（約 2.27 萬平方米），公司自用辦公。**1H26 資本支出 RMB 390.6 百萬，主要就是這筆物業**，所以規格 D11 的「1H26 資本支出 3.91 億」不應當作算力資本支出。
- **中科加禾（約 60%）**：2026-07-21 完成；持股約 60% 只有企查查工商登記（媒體引用），沒有公司公告；對價媒體只寫「數億元」，「2.92 億」找不到原文。標的是異構算力軟體棧與編譯優化（中科院計算所編譯實驗室背景），2023 年成立，前五輪累計融資約 1.3 億元。

## 五、管理層目標（規格 D22 ①）

- 唯一的量化指引是 **ARR**：2026-09-16 電話會把年末 ARR 指引從 US$2.4bn 上調至 US$3.0bn，當時全公司 ARR 為 US$1.8bn；8 月 API 月收入年化約 US$1.6bn。ARR 定義未揭露。
- 中期業績公告的「未來展望」沒有營收、毛利率、獲利時點或算力投入的量化目標，只有質化句子（「毛利率有望企穩回升」）。**結論：量化獲利目標可能不存在。**
- ARR 是公司對配售與可轉債投資人說的，誘因很強，只能作 Reverse 對照，不能反推參數。
