## 2. 口徑說明

- **分部與業務線（重要）**
  - 招股章程用兩個分部：本地化部署、雲端部署。
  - 2025 年度業績公告起，公司「優化收入分類披露」，改成四條業務線：
    - 開放平台及 API
    - 企業級智能體
    - 企業級通用大模型
    - 技術服務及其他
  - 法定分部附註仍是本地化部署與雲端部署兩個。對帳結果：
    - 雲端部署收入＝開放平台及 API 收入（FY2025：190,379；1H2026：825,176 千元）。
    - 本地化部署收入＝智能體＋通用大模型＋技術服務三線合計（1H2026：55,561＋67,037＋6,118＝128,716）。
  - 媒體所說的「本地化部署 5.339 億」就是 FY2025 本地化部署分部（533,955 千元），「雲端 API 1.904 億」就是開放平台及 API。
  - 四條業務線最早只有 FY2024 比較數。FY2022–FY2023 只有兩分部口徑。
- **GLM Coding Plan 的歸屬**：公告沒有單列 Coding Plan 收入，判定它在「開放平台及 API」內（標 Derived），依據有三點：
  1. 年度業績公告在開放平台及 API 的毛利討論裡提到「programming subscription packages」。
  2. 中期公告說 Coding Plan 是雲端訂閱。
  3. 雲端分部恰好等於開放平台及 API，其餘三線加總恰好等於本地化部署，沒有其他位置可放雲端訂閱。
- **經調整淨虧損（非 IFRS）**：等於期內虧損加回三項：
  - 以權益結算的股權報酬
  - 向投資人發行的金融工具賬面值變動（上市前優先權工具；FY2025 為 9.37 億，1H2025 為 4.29 億）
  - 上市開支

  上市後，投資人工具這一項大幅縮小（1H2026 只有 0.22 億），所以經調整與法定虧損的差距收窄。
- **算力服務費**：
  - 招股章程概要只揭露**銷售成本內**的計算服務費：FY2023 1,200 萬、FY2024 3,017 萬、1H2025 3,585 萬。
  - **研發開支內**的算力服務費（金額大得多）只能取自媒體轉述：2022 0.15 億、2024 15.52／15.53 億、1H2025 11.45 億，占研發七成以上。原始財務資料節沒能讀取。
  - FY2025 與 1H2026 的公告都只說成本或研發增加「主要因算力服務費」，沒有給金額。
  - 旁證是資產負債表上的「應付算力服務費」：2024 年末 2.69 億、2025 年末 7.27 億、2026 年 6 月末 14.27 億。1H2026「預付算力服務費及其他」12.44 億。
- **其他收入**：公告都沒有拆出政府補助。1H2026 其他收入增加，公告歸因於上市後存款的利息。1H2026 有非流動遞延收益 1.73 億，性質未說明，不確定是否為政府補助。
- **金額單位**：一律換算成 RMB 億（千元÷100,000；百萬÷100）。虧損以正數記；現金流出以負數記；分部毛利為負時保留負號。
- **資本開支**：
  - FY2024 4.623 億、FY2025 0.747 億。公告說下降是因為「由租賃轉為採購服務」。
  - 1H2026 3.906 億，主因收購北京紅鑽。媒體寫的 3.91 億是同一數字四捨五入，不算矛盾。
- **人數**：只有三個時點有全職員工人數：2025-06-30 883 人、2025-12-31 1,094 人、2026-06-30 981 人。研發人數只有 2025-06-30 的 657 人。人均薪酬是 Derived，以期末人數計算，薪酬含股權報酬。
