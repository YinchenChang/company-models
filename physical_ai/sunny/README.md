## 命題
命題：舜宇光學的股價由手機模組的低毛利底部（上半年 12.3%）能否被車載（毛利率 30%）與其他產品（機器人、智慧影像）的成長抵銷決定；機器人與 Robotaxi 相機模組（線 6）目前規模極小，是選擇權而非承重項

**結論（條件式）：** 在 FY2026 營收情境 B 年增 8.1%（公司指引不低於 7%）、FY2027–28 車載年增 10%、同業前瞻 P/E 中位數 14.8 倍的基準假設下：加權目標價 102.06 港元（DCF 121.55、Comparable 82.56），上檔空間 +74.5%，估值評等 強力買進；收支關卡 通過（情境 B FY2026–30 自由現金流扣股利 24,285 百萬人民幣）；投資建議 強力買進

距最近級距邊界 24.5 個百分點；翻轉目標價（升一級／降一級）已在最高級／87.75 港元。上檔三段歸因：DCF +53.9%、未調整 Comparable +20.6%、相對倍數調整 +0.0%

命題回覆：問：車載與其他產品成長能否抵銷手機低毛利並支持高於現價的目標價？答：情境 B FY2028 EPS 4.75 人民幣（5.58 港元），現價只有其 10.5 倍，同業中位數 14.8 倍；加權目標價 102.06 港元。問：實體 AI 有多重要？答：情境 B FY2030 機器人與 Robotaxi 相機模組子列只占合併營收 0.08%，結論不靠它（模型輸出，非獨立證據）。

**讀法：** 現價 58.50 港元只有模型情境 B FY2027 EPS 的 11.7 倍，資料商現行前瞻 P/E 約 12.2 倍、同業 3 家中位數 14.8 倍（Analogy，家數少）；DCF 另有淨現金 約 13,464 百萬人民幣（含理財資產 13,327，約占市值四分之一）。結論主要建立在 Assumed 的分部成長與毛利率、Analogy 的同業倍數，以及理財資產可全額變現的假設上；機器人與 Robotaxi 相機模組子列（情境 B FY2030 占營收 0.08%）不是承重項。

**證據邊界：** 上檔主要來自 DCF（單獨 121.55 港元，+107.8%），而 DCF 的折現率偏低（rf 1.61%、β 1.13、WACC 7.79%）；ERP 取 6% 時加權目標價 96.00 港元。只看情境 C：61.38 港元（+4.9%，中立）。同業 P/E 取低端（LG Innotek）：81.06 港元（買進）。基準評等「強力買進」在情境 C 與同業低端下不成立。
