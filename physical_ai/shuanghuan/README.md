**讀法：** 情境 B 營收 10,120 → 11,018 → 11,853 → 12,620 → 13,326 → 13,973 → 14,592（FY2026→FY2032，百萬元）；新能源車齒輪占合併營收由 45%（FY2025）升到 57%（FY2032）。結論主要建立在 Assumed 輸入（各分部年增、毛利率、資本支出路徑）上，Verified 的部分是 FY2024–FY2025 年報與 2026 年第 3 季實績；最敏感的輸入見下表與 Recon 反解。

## 命題

1. **營收結構：** 官方分部為乘用車齒輪（2025 年 6,005 百萬元，占 66%；其中新能源車齒輪 4,102）、商用車、工程機械、電動工具與摩托車、智能執行機構、減速器及其他；各分部由年增推導。
2. **新能源車齒輪：** 外包趨勢與海外廠帶動，2025 年 +21.7%；模型首年增（FY2027）情境 A／B／C＝24%／16%／8%，之後逐年衰減。標記 Assumed。
3. **機器人減速機（RV）：** 營收＝前一年 × 線 6 RV 市場成長 ×（1＋份額漂移）；線 6 RV 市場 2026→2030 基準幾乎持平（只來自傳統工業機器人），人形不增量，因此不是成長來源。
4. **獲利與現金：** 毛利率 FY2026 26.7%、FY2030 情境 A／B／C＝28.5%／27.2%／25.5%；資本支出 2024–2025 年占營收約 22%，FY2027 起假設降到 15%，這是自由現金流與 DCF 的關鍵假設。

情境 B：營收 10,120 → 11,018 → 11,853 → 12,620 → 13,326 → 13,973 → 14,592；毛利率 26.7% → 26.8% → 27.0% → 27.1% → 27.2% → 27.2% → 27.2%；EPS 1.59 → 1.77 → 1.94 → 2.11 → 2.27 → 2.38 → 2.49 元（FY2026→FY2032）。
