AI實體應用專案的底層線模型之一（AMR、AS/RS、單件揀選手臂、倉儲人形）。框架：`線3_倉儲物流_框架_v0.1.md`（Drive `02-Projects/10-AI實體應用/`）。

## 建置

```
python3 build_warehouse.py
```

產生器寫出 Excel → LibreOffice 重算 → 檢查。檢查不過時結束碼為 1。檢查項目：
1. 全部工作表 0 個錯誤值。
2. 計算、情境、敏感度頁的每個 Excel 重算值，與 Python 用同一條運算式求得的值一致（相對誤差 < 1e-6）。
3. 敏感度頁每個區塊的排序第一名就是擺幅最大者。

## 頁面

說明｜輸入｜計算｜情境｜敏感度｜下游取數｜追蹤指標

- **輸入**：藍字＝輸入，黃底＝判斷值。每列都有低／基準／高、標記（[Verified]／[Interested-party]／[Analogy]／[Assumed]）、類別（[P]／[A]／[I]）、出處、日期。計算頁一律讀基準欄。
- **計算**：框架第 3 節的等式。每台 AMR 回本期、每埠（＝每座倉）AS/RS 回本期、每訂單行處理成本（人工、AMR 貨到人、AS/RS、AS/RS＋手臂）、人形每人工當量小時成本、市場與份額對照。
- **情境**：市場 2025–2032 低／基準／高；單位經濟 2026–2032 悲觀／基準／樂觀。悲觀／樂觀的定義是：該輸出敏感度前 3 名承重變數同時取不利端或有利端，再加上年度驅動（降價、時薪成長），其餘取基準。年營運時數 H 是場址設定，情境固定 2 班，影響只在敏感度頁呈現。
- **敏感度**：每個輸入單獨取低或高，依擺幅排序。排序表放在基準結果前面。
- **下游取數**：代號 `WH_*`，含低／基準／高、單位、口徑、來源儲存格。

## 固定規格

- 以 Andy 2026-11-16 指示的線模型規格為準：藍字輸入、公式可追溯、標記欄、Analogy／Assumed 給三值、LibreOffice 重算 0 錯誤值。
- 下游至少要有：AMR 與 AS/RS 市場規模情境（`WH_AMR_MKT_*`、`WH_ASRS_MKT_*`）、AMR 回本期（`WH_AMR_PAYBACK*`）、各方案每單位處理成本（`WH_COST_*`、`WH_HUMANOID_COST_HR`）。
- 公開 repo，不放任何個人情境或部位。

## 已知限制（v0.1）

- AMR 單價、AS/RS 系統價、維運費率都來自利害關係人（供應商、整合商），沒有取得獨立報價。維運費兩個來源互相衝突（5–8% 對 12–20%），區間取兩者聯集。
- 手臂價格與速度、人形相對生產力都是假設值，對應輸出信心低。
- 只用美國人工當基準。
- 行動機器人市場用 Interact 口徑（含製造業、自主堆高機），AS/RS 用 MarketsandMarkets 口徑。兩者不能相加。
