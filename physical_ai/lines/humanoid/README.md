# 線 2b 人形機器人單位經濟（只做硬體）

這是 AI實體應用專案排定的第一個交付物。它從全尺寸人形機器人（Optimus Gen 2 類：16 個旋轉關節、14 個線性關節、2 隻靈巧手）的每台 BOM 算起，依序推到製造成本、售價、使用端 TCO 與回本期，再套學習曲線推到 2026–2035 年。設計稿是框架檔《線2b_人形機器人_框架_v0.1.md》第 3 節。

| 項目 | 內容 |
|---|---|
| 版本 | v0.1（2026-11-16） |
| 成品 | `dist/20261116_人形機器人單位經濟_v0.1.xlsx` |
| 產生器 | `python3 build_humanoid.py`：所有計算都寫成 Excel 公式，存檔後用 LibreOffice headless 重算並寫回，讓下游可以用 `data_only` 讀到快取值。加 `--no-recalc` 可略過重算。 |
| 核對 | `python3 check_humanoid.py`：重算後要求 0 個錯誤值，核對頁全部 PASS，並印出下游取數與敏感度排序 |

## 頁面

說明 → 輸入 → **敏感度**（承重變數排序，放在基準結果之前）→ 計算 → 情境（2026–2035，低／基準／高）→ 下游取數 → 追蹤指標 → 核對

## 固定規格

- 藍字是輸入，黃底是判斷值（Assumed／Analogy）或可以改的選擇。每個輸入都有類別 [P]／[A]／[I]、標記（[Verified]／[Interested-party]／[Analogy]／[Assumed]／[Derived]）、出處與日期。
- Analogy、Assumed 一律給低／基準／高三個值。使用值的規則是：覆寫欄有值就用覆寫，否則用基準。
- **行星滾柱絲杠單價有五個互相矛盾的出處**（雙林 ¥499、五洲新春 2025 年均價約 ¥1,360、國際品 >¥5,000、MS 1,350–2,700 美元），因此不取單一值，改成情形選擇（輸入頁 G 表，基準選 3），敏感度頁 C 表列出五種情形的結果。
- 全球平均每台用量＝全尺寸用量 × 採用比例。原因是中國小型機大多不用絲杠，旋轉關節也多用行星減速。
- 本資料夾在公開 repo，不放任何個人情境。

## 下游取數（`下游取數` 頁；每列另有具名範圍 `DS_<代號>`，指向基準值）

- `HUM_BOM_2026`：每台 BOM。`HUM_BOM_SCREW_CASES`：絲杠情形 1／3／5 下的每台 BOM。另有 `HUM_MFG_2026`、`HUM_PRICE_2026`、`HUM_PAYBACK_2026`、`HUM_BOM_REQ`、`HUM_PROD_REQ`。
- 零組件單價 `P_*`、每台用量 `Q_*`、每台價值 `V_*`（諧波減速機、滾柱絲杠、無框馬達等）。
- 全球人形出貨量情境：`SHIP_2026` 到 `SHIP_2035`。
- 人形用諧波減速機與滾柱絲杠：需求量 `HARM_UNITS_*`、`SCREW_UNITS_*`；市場規模 `HARM_MKT_*`、`SCREW_MKT_*`；全球平均每台用量 `Q_HARMONIC_AVG`、`Q_SCREW_AVG`。
- 成本路徑：`HUM_BOM_2028`、`HUM_BOM_2030`、`HUM_BOM_2035`（及同年份的售價）。跨過回本門檻的年份：`HUM_CROSS_YEAR`。

## 已知限制（v0.1）

- 以下項目的單價都還沒取得，目前以 [Assumed] 區間代替：無框馬達、編碼器、驅動板、軸承、線束；另外良率、MTBF、相對人工生產力也沒有公開數據。
- 售價是用「製造成本 ÷（1 − 毛利率）」推出來的，不是任何廠商的列表價。
- 學習曲線用的是全產業累積出貨，零組件單價也按同一比例下降。
- Goldman 2035 年 648 萬台究竟是年度量還是累積量，原出處沒有寫清楚。
