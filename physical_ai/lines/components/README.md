`build_components.py` → `dist/20261116_共用零組件單位經濟_v0.1.xlsx`

```
python3 build_components.py --recalc   # 產生 xlsx，用 LibreOffice 重算，檢查錯誤值與內部檢核
```

## 核心等式

- 需求量(c, y) ＝ Σ_line 出貨量(line, y) × 每台用量(c, line)
- 市場規模(c, y) ＝ Σ_line 出貨量 × 用量 × 價格乘數(c, line) × 單價(c, y)
- 單價(c, y) ＝ 2026 單價 ×（1 − 年降幅）^(y − 2026)
- 稼動(c, y) ＝ 需求量 ÷ 產能（諧波、RV、行星滾柱絲杠、LiDAR）

線：工業機器人（傳統、協作）、人形、運輸物流機器人（AMR）、輕型車（全部、搭 LiDAR、搭 EMB、搭 SBW）、Robotaxi 新增車輛。

## 固定規格（v0.1）

1. 頁面：說明｜輸入｜計算｜敏感度（排序表在前、基準結果在後）｜情境｜供需｜份額｜下游取數｜對帳｜追蹤指標。
2. 藍字＝輸入，黃底＝判斷（Assumed／Analogy），黑字＝公式；每列輸入附標記與出處；Analogy、Assumed 給低／基準／高三值。
3. 口徑＝「五線歸因」：只計上列各線拉動的需求，不含工具機、半導體設備、割草機等。
4. 情境＝需求面同向（出貨量 × 用量）；單價一律用基準路徑，單價不確定性在敏感度，行星滾柱絲杠另有「需求情境 × 單價口徑」3×3 矩陣。
5. 行星滾柱絲杠單價三口徑（MS 推算、覓途占比推算、中國量產價）並列，不選邊。
6. 不重複合計不含靈巧手模組（與空心杯、觸覺重複）、車用相機（既有需求為主）、運算（AI供應鏈權威）、電池、結構件。
7. 人形每台用量是**出貨組合平均**，不是 Optimus 類單機；Optimus 類數字列在出處欄。
8. 驗收：LibreOffice 重算後 0 錯誤值；`說明!C2`（依線拆分合計 − 不重複合計）＝ 0。

## 對帳

各線出貨量為暫用值（其他五線模型同時建），集中在「對帳」頁；粗體列待其他線模型完成後替換。
