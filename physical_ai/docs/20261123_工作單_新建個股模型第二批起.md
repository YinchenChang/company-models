## 模型規格
- 檔案：`build_<資料夾>.py`（一支程式產生整本，藍字輸入、公式可追溯）、`segments.json`、`sens.json`、`README.md`、`dist/20261123_<公司名>個股模型_v0.1.xlsx`（LibreOffice 重算後存檔，0 錯誤值）。
- 工作表至少：README、In、Hist、PL、DCF、Val、Sens、Recon、對帳、Sources（比照範本；具名儲存格 `px`、`px_date` 必備；Val 頁要有以「加權目標價」開頭的列與以「入不敷出判定用」開頭的列，地圖靠這兩列抽數）。
- **PL 頁做成標準損益表**（營收、年增率、營業成本、毛利、毛利率、營業費用、營業利益、營業利益率、業外、稅前、所得稅、淨利、淨利率、EPS、淨利年增率；歷史 3 年＋預估 5 年），讓 `check_layout_v13.py` 的 D 項能真的通過，不要用「未建模」佔位。公司沒有揭露的拆分（例如只揭露營業利益）才標「未揭露」。
- 命題＋營收分部：分部營收由驅動因子推導；凡用到線層級變數（出貨量、市場規模、每台用量、滲透率、每英里成本等）一律讀線模型「下游取數」的值（寫明來源檔與儲存格），列在「對帳」頁；與線模型不一致的自設值要標明並說明理由。
- 估值：DCF（依標準規格）與 Comparable 加權；三情境 A／B／C；五級評等（> +50% 強力買進、+25%～+50% 買進、−25%～+25% 中立、−50%～−25% 放空、< −50% 強力放空）；收支關卡＝FY2026–FY2030 情境 B 自由現金流扣股利合計。
- 現價：2026-11-20 收盤，取自 `physical_ai/data/closes2_20261109_20261120.csv`（Yahoo Finance 日線；欄位 symbol,currency,date,close）；同業報價也用這個檔（沒有的同業標「報價日未取得」並說明）。若檔內沒有這家公司，回報並停在「缺現價」，不要自己找價格填入。
- 資料：用 WebSearch／WebFetch 查公司最新財報與指引（優先公司原始文件、交易所公告；其次資料商）。每個輸入標 Verified／Interested-party／Analogy／Assumed／Derived，附出處；Analogy、Assumed 給區間。**搜尋額度有限：控制在 25 次搜尋以內**，先查會動到目標價的輸入。查不到的寫「未找到」，不臆造。
- 台股（代號為台灣上市櫃）：對外不公開目標價，做法照 `physical_ai/hiwin/`；HTML 不放任何目標價（含賣方目標價圖）。
- 新近上市、財報期數不足或未公開的公司：照高不確定性原則，縮小模型到證據支撐得住的範圍（例如只做營收與毛利推導加區間估值），在 README 開頭寫明哪些部分沒有做、缺哪一項輸入。
