## 命題
命題：Regal Rexnord 是以工業傳動、電機與資料中心電力設備為主的高槓桿工業公司；股價由資料中心帶動的電力與運動控制營收、毛利率與償債速度決定，無框力矩馬達（Kollmorgen，人形機器人用）只是小型選擇權

**結論（條件式）：** 在 FY2027 AMC／IPS／PES 情境 B 營收年增 8%／2%／5%、同業前瞻 P/E 中位數 15.7 倍的基準假設下：加權目標價 159.89 美元（DCF 137.47、Comparable 182.32），上檔空間 +5.0%，估值評等 中立；收支關卡 通過（情境 B FY2026–30 自由現金流扣股利 6,104 百萬美元）；投資建議 中立

距最近級距邊界 20.0 個百分點；翻轉目標價（升一級／降一級）190.44／114.26 美元。上檔三段歸因：DCF -4.9%、未調整 Comparable +9.8%、相對倍數調整 +0.0%

命題回覆：問：資料中心帶動的電力與運動控制成長能否支撐高於現價的目標價？答：情境 B FY2028 調整後 EPS 12.00 美元，現價 152.35 美元是其 12.7 倍，同業中位數 15.7 倍；加權目標價 159.89 美元。問：人形機器人有多重要？答：情境 B FY2030 無框力矩馬達增量只占合併營收 0.85%，結論不靠人形（模型輸出，非獨立證據）。

**讀法：** 現價 152.35 美元約為公司調整後 EPS 指引中點 10.75 美元的 14.2 倍；Comparable 只用 3 家日本同業中位數 15.7 倍，且套在自定義調整 EPS 上，可信度低。結論主要建立在 Assumed 的分部成長率與毛利率，以及面窄的同業倍數上；無框馬達增量（情境 B FY2030 占營收 0.85%）不是承重項。
