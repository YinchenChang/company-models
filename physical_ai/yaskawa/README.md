## 命題（線 2a 的證偽測試）

- **命題**：安川訂單創新高（2026 年 6–8 月受注 1,854 億日圓 +38%；運動控制 911 億 +56%、機器人 776 億 +33%），驅動是半導體設備與資料中心（驅動器）；但機器人利益率由 FY2024 10.0%、FY2025 8.3% 降到 H1 FY2026 5.0%。問題是：利益率下滑是一次性（歐洲重組約 1.8、核心系統 S/4HANA 切換）還是結構性（中國價格戰、汽車需求平）？
- **命題模組**（Thesis 頁）：季度受注、受注 ÷ 營收、機器人與運動控制利益率序列、Q1 一次性加回、四個證偽測試。
- **目前讀數**：T1 訂單強成立（機器人受注 ÷ 營收 Q2 FY2026 1.26、運動控制 1.31）；T2 Q2 FY2026 機器人利益率 8.2%，對 Q2 FY2025 約 8.7% 仍略降（−0.5pt）；Q1 加回一次性後僅 5.1%，Q2 回到 8.2% 是改善訊號。
- **失效條件（可觀察）**：(1) H2 FY2026 機器人利益率低於 8%（公司指引隱含 8.9%；2027-04 決算）→ 偏情境 C；(2) FY2027 機器人利益率 < 8% 而營收年增 > 5% → 量增不增利為結構性，命題證偽；(3) 運動控制受注 QoQ 連兩季下降 → 半導體循環見頂，情境 C 的 FY2028 −6%。
- 人形機器人、AI 機器人（MOTOMAN NEXT）：Dash 35 列為方向，無營收揭露，本版不建子列（併入機器人成長率），對帳頁標 2b「未使用」。
