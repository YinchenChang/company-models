## 命題
命題：Novanta 的股價由兩件事決定：ATI 力感測與工業精密元件（AET）能否維持高於營收的獲利成長，以及併入 Riverpoint 後的醫療部門與槓桿能否消化；人形機器人六維力感測是小型選擇權，不是承重項

**結論（條件式）：** 在 FY2027 AET 年增（情境 B）8%、Medical 年增 22%、FY2027 調整後 EBITDA 率 25.3%、同業前瞻 P/E 中位數 15.1 倍的基準假設下：加權目標價 53.03 美元（DCF 38.85、Comparable 67.21），上檔空間 -48.0%，估值評等 放空；收支關卡 通過（情境 B FY2026–30 自由現金流扣稅後利息 1,288 百萬美元）；投資建議 放空

距最近級距邊界 2.0 個百分點；翻轉目標價（升一級／降一級）76.49／51.00 美元。上檔三段歸因：DCF -31.0%、未調整 Comparable -17.0%、相對倍數調整 +0.0%

命題回覆：問：AET 與醫療能否支持高於現價的目標價？答：情境 B FY2028 調整後 EPS 4.37 美元，現價是其 23.3 倍，高於同業中位數 15.1 倍；加權目標價 53.03 美元。問：人形六維力有多重要？答：情境 B FY2030 子列只占合併營收 2.3%，結論不靠人形（模型輸出，非獨立證據）。
