**讀法：** 這家公司的價值幾乎全在制冷與汽車熱管理兩個既有板塊；情境 B 人形致動器營收 0 → 156 → 438 → 997 → 1,975 → 2,598 → 3,391（FY2026→FY2032，百萬元），占合併營收只從 0% 升到 6.3%，因此人形假設對目標價影響有限（見敏感度）。結論主要建立在 Assumed 的板塊成長率、毛利率與 Derived 的同業倍數上；與市場價格的差距主要來自折現率與同業倍數的選擇。

## 命題

1. **營收結構：** 官方分產品為制冷空調電器零部件（2025 年 18,585 百萬元，占 60%，含資料中心液冷）與汽車零部件（12,427）；機電執行器未單獨揭露，本模型另列一行（FY2026＝0）。
2. **量與價：** 兩個既有板塊以年增率推導（Assumed，參考第 3 季制冷 +6.5%、汽零 +9.6%）；人形致動器＝線 4 出貨 × 全尺寸等效係數 0.50 × 每台 BOM × 致動器占比 64.3% × 份額 × 匯率。
3. **利潤：** 毛利率由第 3 季 28.89% 線性走到 FY2030 29.5%（情境 B）；費用率 13.1% → 12.5%。

情境 B：營收 32,745 → 35,330 → 38,221 → 41,584 → 45,576 → 49,437 → 53,709；毛利率 28.9% → 29.0% → 29.2% → 29.3% → 29.5% → 29.5% → 29.5%；EPS 0.98 → 1.17 → 1.28 → 1.42 → 1.58 → 1.72 → 1.86 元（FY2026→FY2032）。

## 限制與「分不出來／沒找到」

- **分不出來：** 人形致動器金額公司未揭露；液冷規模未揭露，併入制冷成長率。
- **沒找到：** 2026 三季報資產負債表與現金流、1–9 月分板塊營收；本公司 β；市場共識目標價；客戶集中度（年報前五大客戶占比未查）；2023 年分部營收。
- **線模型不一致：** 線 6「人形每台零組件內容」（約 2.3 萬美元）口徑窄於本模型致動器價值（線 4 BOM × 致動器占比，約 3.9 萬美元）；本模型用線 4，差額以份額吸收。見 xlsx「對帳」頁。
- **同業倍數：** 核心 4 家（美的、匯川、拓普、雙環）；美的、匯川以券商 2027E EPS 反推，拓普、雙環用資料商 NTM 共識由原報價日換算至 2026-11-20；兆威、鳴志倍數被機器人預期主導，不進中位數。海爾智家、格力電器、盾安環境、銀輪股份報價日未取得前瞻 EPS。
- **rf 逾期：** 中國 10 年期國債 1.61% 為 2026-11-05 值（跨模型一致）。
- **協調檔：** 實體 AI 模型不讀 Siliconomics／Tokenomics／Wattonomics。
