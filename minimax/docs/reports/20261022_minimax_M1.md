## 4. 歸因（以 v5.24 為底，一次只換一組）
| 組 | 名稱 | 影響 |
|---|---|---|
| ① | `IF_TokGW_*` | **全部**輸出變動來源：η −34%（吸收絕對水準）；API MW 2027–30 −0.4%～−0.7%；VR 等值係數 +17% |
| ② | `IF_Util` | 0.60 未變，影響 0 |
| ③ | `IF_HoldEcon`／`IF_FullCost_*` | 只改對照列 C29（10.10→9.70）；不進公式，其他輸出 0 影響 |
①+②+③ 與「全部換新」的差為 0（無交互作用）。

**驗證審視報告的論點**：η 校準吸收產能絕對水準。證據：①Luna／Sol 每 GW 產能上調 51%～57%，η 反向下調 34.3%（1/1.52～1/1.57 的混合，60／40 層級權重下相符），2025、2026 的 API MW 與所有 2025–2026 輸出逐格不變；②2027 起 API MW 只因「Blackwell ÷ Hopper 產能比」微升（Luna 4.891→4.970、Sol 4.845→4.868）而變動 −0.4%～−0.7%，且 API 推論只占總 MW 約 12–17%，傳到總 MW 僅 −0.1%。結論：**本模型的 Tokenomics 產能只剩世代比例起作用**，絕對水準對 MW、覆蓋率、融資皆可忽略。
