# 歷史相對倍數規格：PS 與 PSG（software_ai，2026-11-17）

**依據：** Andy 2026-11-17 07:38：「跟同業比的歷史估值溢價或折價：除了市銷率（PS），也用市銷率／營收增長率（PSG，ps/g）。其他按預設。」本規格適用 `software_ai/` 所有個股模型的 Comparable 相對倍數（原則第 18、47 條；工作單 G3 第 4 條）。

## 1. 定義
- **PS**＝市值 ÷ TTM 營收（季末，市值取季末收盤 × 季末流通股）。
- **PSG**＝PS ÷ TTM 營收年增率（以百分點計，例：成長 25% → 25）。TTM 營收年增率 < 2% 或為負時該點記 N/M，不進統計。
- **相對值：** 本公司 PS ÷ 同業中位 PS；本公司 PSG ÷ 同業中位 PSG。同業組與本模型 Comparable 同業相同；同業該季資料缺漏時以其餘家計中位數，少於 2 家該季記 N/M。
- **期間：** 最近 5 年、每季一點；有效點 < 12 的序列視為取不到（讀數只作參考、不進基準），由 `relmult_hist.py` 強制。各公司會計季末不同時，以日曆季末最近的財季對齊，寫明對齊方式。

## 2. 用法
1. 兩條歷史序列各取中位數（基準）、最低、最高（Sens 區間）。
2. **PS 讀數**＝PS 歷史相對中位數。
3. **PSG 讀數**＝PSG 歷史相對中位數 × 目前「本公司 ÷ 同業中位」的 NTM（取不到則 TTM）營收成長比——即把歷史上「每單位成長的溢價」換算成今天應有的 PS 相對值。
4. **rel_mult 基準＝兩讀數的幾何平均**（Derived）；Sens 另列「只用 PS」「只用 PSG」兩案。〔Claude 預設，Andy 可撤回〕
5. 兩讀數差異 > 30% 時，README 與 HTML 寫明原因（通常是本公司與同業成長差距改變）。
6. 取不到任何一條時，用可取得的一條並寫明；兩條都取不到才用 1.00 並列承重輸入。

## 3. 資料
- 共用資料庫：`software_ai/data/relmult_hist/`（每家一個 CSV：季末日、市值、TTM 營收、TTM 營收年增、PS、PSG、來源、擷取日）與 `software_ai/data/tools/relmult_hist.py`（計算相對序列與第 2 節讀數，輸出 JSON 供各模型讀取）。
