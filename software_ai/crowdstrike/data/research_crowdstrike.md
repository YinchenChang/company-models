## (1) 公司一句話
雲端原生端點防護起家的資安平台（Falcon），以訂閱授權，客戶依端點、身分與模組數計費，並以 Falcon Flex 做平台額度式授權；2026 年起增加 AI 代理防護（AIDR）與非人類身分相關產品。

- 產品線（10-K Item 1）：32 個雲端模組（FY 年底）、33 個（申報日）；Charlotte AI、AIDR、Identity Protection、Falcon Shield（含非人類身分）。無逐產品營收揭露。

## (8) 爭議
**多方**
1. AI 擴大攻擊面並增加資安支出；2026 年春季「Mythos」後需求轉強。Q2 FY27 淨新增 ARR 332.8M（+51% 年增），FY27 淨新增 ARR 指引上調至約 1.35B（+34%）。來源：Q2 FY27 新聞稿、法說（Kurtz／Podbere，2026-08-26）。
2. AI 代理與非人類身分是新增計價單位：AIDR 獨立計價並含 token 計價，Falcon Shield／特權帳號 ARR 高成長；Kurtz 稱 AIDR 可能大於 EDR。來源：Q2 FY27 法說逐字稿（Webull 轉載）。
3. 平台整併與 Flex：6+ 模組客戶 51%；Flex 帳戶 ARR 2.29B（占 ARR 約 39%），轉 Flex 平均 ARR 增逾 40%；FY27 上半年 FCF 率 30%。來源：Q2 FY27 新聞稿、法說。

**空方**
1. AI 原生廠商直接進入資安：2026-02-20 Anthropic 發表 Claude Code Security 後 CRWD 兩日跌近 20%（2/23 跌 10.6%）；問題在 AI 平台能否自建完整執行期防護。來源：Motley Fool 2026-02-23（Kurtz 以 Claude 自答反駁）。
2. 估值與競爭：評論稱 CRWD 在 21 倍以上營收，易受顛覆與價格壓力；PANW 同樣走平台策略（CyberArk 併購）。來源：Motley Fool 2026-02-23；MarketBeat／Nasdaq 2026-08-28。
3. ARR 與營收認列的資料品質與法律風險：10-Q 披露收到 DOJ 與 SEC 就「特定客戶交易的營收認列與 ARR 報告」之資訊請求，公司表示配合；7 月 19 日事件訴訟中 Delta 案仍在證據開示。GAAP 仍為營業虧損（Q2 FY27 −33.2M），SBC 占營收約 23%。來源：10-Q（2026-07-31）Note 11、10-K FY2026。
