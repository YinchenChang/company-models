# software_ai/paloalto/ — Palo Alto Networks（PANW）個股模型 v0.2.2（原型 P：按防護範圍計價）

**本版未做先驗**（工作單 G 節：先驗跳過）。工作單：`software_ai/docs/workorders/20261116_第一批_研究包與單位經濟.md`（共同規則、研究包格式、G、G2、G3）。

**建置：** `bash software_ai/paloalto/make_paloalto.sh`（約 1.5 分鐘；含敏感度整本重算、html.json、HTML 與全部核對，包含 `check_rating_gate.py --strict`）。成品 `dist/20261124_Palo Alto Networks個股模型_v0.2.2.xlsx`／`.html`。投資建議、目標價與各數字見成品 README 頁與 HTML（由公式組字，本檔不手寫）。

**命題：** AI 讓資安的受保護範圍從人與端點擴大到代理（非人類身分）。NGS ARR ＝ 受保護單位 × 每單位營收；每單位營收 ＝ R0 ×（1 − 價格侵蝕 ＋ 模組加購 ＋ 代理身分數 × 代理單價比）；推論成本 ＝ 分析次數 × 每次 token × 市場價，只讀 Tokenomics v22.0 快照（`software_ai/unit_economics/data/tk_snapshot.json`）。變數名稱沿用 `software_ai/unit_economics`（P_mod、P_px、P_rho、P_n26／n32、P_m26／m32、P_e26／e32、P_k26／k32、P_tier、g_px、g_tok、ovh）；該模型 v0.1 完成前在本模型 In 頁自建，v0.2 改讀 unit_economics。

**結構：** README、In、Q、Hist、TK、PL（情境 B）、PL_A、PL_C、Val、RevDCF、Recon、Sens、Sources。官方分部只有一個（10-K 附註 19）；營收列取 Product 與 Subscription and support。估值＝FCFF DCF（至 FY2032，期中折現，終值 NOPAT×(1−g/RONIC)/(WACC−g)）與同業 P/S 的 Comparable 各半，情境 25／50／25。會計年度 7 月底；FY2026 含 CyberArk（2026-02-11 完成）。

**檔案：** `build_paloalto.py`（Excel 產生器，全部活公式）、`gen_html_json.py`（依列標籤產生 `html.json`）、`segments.json`、`make_paloalto.sh`、`data/`（研究包 `research_paloalto.md`、`facts_paloalto.csv`、`make_research.py`、`sens_v022_20261124.json`）、`dist/`。

## G3 合理性關卡診斷
觸發（v0.2.2 重跑，仍成立）：DCF 目標價（約 49 美元）低於現價（353.43）的 25%、評等強力放空；FY2027 營收（對新指引高 0.04%）與非 GAAP 營業利益率（低於指引 0.6 個百分點）差距都未超過 10%。診斷：費用率已依歷史規模經濟延伸（Non-GAAP 營業利益率每年 +0.3pt，SBC 占營收每年 −0.5pt，標 Derived，全期持平案為 Sens 下緣）；將費用率改善、折現率下調、終值替代法同時取最樂觀，DCF 目標價仍遠低於現價；現價隱含核心營業利益率超過 100%。結論：經濟判斷（現價依賴 FY2032 之後長期高成長，而終值只給 RONIC＝WACC），不是建模錯誤。數字見成品 README 頁「合理性關卡診斷」列（公式組字）。
