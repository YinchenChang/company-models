# LY Corporation（東證 4689）個股模型 v0.2.3

資料截止日 2026-11-16（FY2026 第 2 季，4 月制；Kakaku.com 公開收購事實更新至 2026-11-24，不影響模型數值）。本版沒有做先驗（未預先設定任何投資觀點，結論全由 Assumed 輸入與公開資料推出）。

## 命題
原型 A（按廣告計價）單位經濟：搜尋廣告 = 查詢量 x 廣告負載 x CTR x CPC。LY 不揭露查詢量與 ARPU，故以「查詢分流占比」與「AI 轉換率帶動的價格提升」兩個 Assumed 區間取代，另加官方帳號 AI Mode 增量與 Agent i 訂閱／廣告。推論成本只讀 Tokenomics 快照（`data/tokenomics_snapshot_v22.0.json`，只用 IF_／L1_／SRC_ 名稱），不自行估價。

## 情境分化依據
A／B／C 只在四個 AI 驅動分化：查詢分流占比（10%／20%／35%）、價格提升（15%／8%／2%）、AI Mode 增量（12%／6%／0%）、Agent i 付費占比（6%／3%／1%）。依據：公司只揭露 AI 功能使用者購前轉換 1.7 倍（非隨機對照）與 Agent i 計費起點，沒有量化 AI 營收；分化幅度為判斷，不是觀測值。FY2032E AI 淨效果（營業利益，十億日圓）A／B／C = +52.3／+10.4／-33.4。其他分部成長三情境相同。權重 25／50／25（Assumed）。

## 不適用項目
- 不適用：非 Siliconomics 覆蓋。三層協調（Coord 頁、C0、兩個讀數）不做；對帳中兩讀數目標價亦不適用。
- 不適用：LY 不自建算力，只向模型商購買推論。Tokenomics 自用 AI 讀法 2 與 Wattonomics 對照不做。

## 與標準規格的偏離
1. 永續成長率 2%（標準 3%）：JGB 10 年期 2.89%，3% 偏高。
2. beta 0.9 為 Assumed，未取兩來源 Blume 調整中位數。
3. 資產負債表取 2026-09-30，現價取 2026-11-16。
4. 非控制權益以帳面 x 1.5（Assumed）。
5. 同業倍數（Analogy）：Peers 頁 11 列，多數資料日逾期，會計準則與租賃處理多數未取得；本公司 5 年歷史相對倍數自算（財報年度值，非月資料）。
6. PayPay 銀行未模擬存放款，營運資金只以營收增量比率估計（歷史比率未取得）。
7. 股數：封面發行股數 − 庫藏 + 股票交付信託股（視同 RSU）；選擇權、可轉債、ASR 未取得，記 0。
8. 淨債務含全部 IFRS 16 租賃負債（與 FCFF 資本支出含使用權資產一致），租賃負債金額未單獨取得。

## G2／G3 共通必修落實（v0.1.1）
G2：(1) 公司未揭露 token 量與代理任務量，無法校準，維持 Assumed 並標明，token 價格層級標 Analogy；(2) ptok 高案標上界，另有價格與成本聯動、模型路由兩個組合案例；(3) 營業利益率與營業成本率基準持平於最近四季實績（15.1%），收斂只在 Sens；(4) 股數以封面為主來源；(5) 淨債務口徑明寫；(6) Comparable 為同業 TTM 倍數 x 目標日 TTM 分部 EBITDA，列同業準則與逾期，揭露現行倍數 / 同業中位數；(7) Val 頁三列（估值評等、入不敷出判定用、投資建議），make 腳本跑 check_rating_gate --strict；(8) README 日期、指引、落差歸因由公式組字，DCF 與 Comparable 落差以公式分解；(9) 反解寫在 Recon（支持現價所需營業利益率 13.6%）；(10) 逾期標示在 Peers 與 Val。
G3：(1) 費用率歷史無單調規模經濟證據（營業費用率 FY2023 至最近四季約 56 至 60% 先降後回），不延伸，Sens 保留高案；(2) 營運資金正值為流出，FCFF 以減項計；歷史比率未取得；(3) 合理性關卡：DCF/現價 1.32、EV 為正、評等中立、營收差距 -1.4% 皆未觸發；FY2026E EBITDA 對公司調整後指引 -14.8% 觸發，診斷為基準持平規則（H1 實績 17.8% 對 15.1%，約 62 十億日圓）加口徑差，是經濟判斷非建模錯誤（README 與 README 工作表 A42）；(4) rel_mult 自算：Media 0.74、Commerce 0.59、Strategic 0.83。

## v0.2 改動（G5）
1. 相對倍數改讀 `software_ai/data/relmult_hist/out/lycorp.json` 的 Media／Commerce／Strategic 分組 `geo_base`（P/S 與 PSG 幾何平均，Derived；base_source 寫在 In 頁）：Media 0.58、Commerce 0.51、Strategic 1.31（v0.1.1 自算為 0.74、0.59、0.83）。Sens 加 ps_only、psg_only、sens.low、sens.high 四個組合案例（三分部同時改）。Comparable 倍數為 EV／EBITDA，以 P/S／PSG 相對值近似套用。Strategic 兩讀數差異 119% 大於 30%：本公司 TTM 營收成長 8.1% 對同業中位 5.5%，成長比 1.46 使 PSG 讀數 1.94 遠高於 P/S 讀數 0.89；同業僅 3 家，結論偏不穩。
2. 無風險利率統一取日本 10 年期 2.77%（2026-11-11，Trading Economics）；距現價基準日 3 個交易日，Val 頁標逾期。
3. Recon 與 HTML 並列 DCF（股票薪酬加回）對照讀數，不進加權目標價。LY 不揭露股票薪酬費用，以權益變動表股份基礎給付代理（營收約 0.05%），加回影響僅約 +3.4 日圓。
4. 合理性關卡重跑：FY2026E EBITDA 對指引 -14.8% 仍觸發，診斷同 v0.1.1（基準持平規則與口徑差異，經濟判斷非建模錯誤）。

## v0.2.1／v0.2.2 改動（G6、G7 與口徑修正）
Comparable 主腿為 P/S：Σ（同業中位 P/S x rel_mult x 目標時點 TTM 分部營收，依日數加權 FY2027E 與 FY2028E）減非控制權益，除以稀釋股數。P/S 以市值為分子，結果已是股權價值，不再扣淨債務（v0.2.1 曾雙重扣除，v0.2.2 修正）；合併營收含非控制權益所屬部分，故扣非控制權益。原因：P/S／PSG 相對值已含利潤率差，不能套 EV/EBITDA；EV/EBITDA 加總降為對照列（rel_mult 取一 782.4、乘現行相對值 795.8），不進加權。同業中位 P/S 讀 `peer_ps_20261113.json`（2026-11-13 現價）：Media 4.41、Commerce 2.91、Strategic 1.44（舊：資料庫最近一季 3.19、2.72、1.12；v0.2.1 用各家 CSV 最近一季 3.19、2.47、1.31）；非 11-13 的同業逐家標逾期（8 列）。Sens 四案（ps_only、psg_only、sens.low、sens.high）加「同業 P/S＝資料庫最近一季中位」案（596.0）。

## v0.2.3 改動（G10 第 3 條，2026-11-24）：Kakaku.com 公開收購重查，未入模型
本版**只改文字**：數值格與 v0.2.2 逐格相同（驗證結果見建置記錄）；加權目標價、DCF、Comparable 與評等不變。適用高不確定性預估工作原則（`docs/plan/高不確定性預估工作原則.md`）：本題只量測，不改模型值。

**重查結果（公司公告為主來源，逐列等級見 `data/facts_lycorp.csv`、`data/research_lycorp.md` 第 5、8、9 節）：**
1. 買付人是 BCPE Blitz Cayman, L.P.（Bain Capital 持有營運），LY 不是買付人；LY 在買付成立後、決済前對其上層持股公司出資。對象者祖父母公司經濟持分 Bain Capital 50.1%／LY 49.9%，表決權 100%／0%（LY 持無表決權股，附轉換請求權）。
2. 更正：舊稿「約 690bn、與 Bain 各約 50%」不成立。690.0bn 是 LY 2026-08-03 簡報對 3,520／3,640 日圓價位的**買付總對價**，不是 LY 出資額，其後已調價且未更新；「各約 50%」是經濟持分，不是出資比例。LY 出資額：未找到。
3. Bain 側價格：2026-07-01 3,384、07-29 3,520、09-16 3,597、10-26 3,700（KDDI 不應募契約成立的條件價依序 3,500、3,640、3,720、3,720）。2026-11-12 的「3,700」是 Kamgras 1 由 3,683 調升，不是 Bain 側調價。
4. 條件：開始後 20 營業日；下限 131,805,000 股（66.05%）、無上限；銀行融資上限 2,700 億日圓（SPV 層）；股份併合生效 3 年後 LY 有買權、Bain 在條件滿足時有賣權，價款公司估最大約 6,000 億日圓（Interested-party）。
5. 狀態：截至 2026-11-24 最新公司公告為 Kakaku.com 2026-11-12 訂正公告；Kamgras 1 買付期間至 2026-11-26；之後的公告未找到。

**若交割，對報表的影響方向（不給點值）：**
- 淨債務：上升（LY 出資為現金流出；若併入報表，SPV 層借款併入；買權／賣權價款若認列為負債亦增加）。
- 非控制權益：若連結則新增（對應 Bain 持分）；若持分法則不產生。
- 合併營收：若連結則增加 Kakaku.com 營收；若持分法則不變，改列持分損益。
- 連結或持分法處理公司未揭露：未找到。

重判觸發：Bain 側公開買付開始或成立；LY 揭露出資額或會計處理；Kamgras 1 結果。
