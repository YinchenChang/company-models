## 1. 範圍
專案範圍由「半導體與零組件（IT 設備，每 GW 37.59 US$B）」擴及**廠房中的機房電力與冷卻**。

- 第一批納入 Vertiv（VRT）、ABB（ABBN）。
- 其他機房設施候選（Eaton、Schneider Electric、GE Vernova、Siemens Energy、Trane、nVent、Hubbell 等）不自動加入，列為補位候選，待 Andy 依重要性排序。
- 廠房中的土建、人工、土地、專業服務不納入個股，只在地圖顯示金額。

## 2. 權威層（同一數字只有一個權威）
| 數字 | 權威層 | 名稱 |

**機房設施供應商個股讀 Wattonomics，不讀 Siliconomics。** 這是 Project 規則 3「硬體供應鏈個股讀 Siliconomics」的例外：廠房拆分的權威本來就在 Wattonomics。Siliconomics 不另建設施模組，以免同一數字出現兩個權威。協調方式：個股與 Wattonomics 有差異時，照規則 3 寫對帳單。

## 3. 邊界：機櫃內歸 IT，機櫃外歸廠房
- **IT（Siliconomics「電源與散熱」）：** 伺服器電源供應器、power shelf、BBU、冷板、機櫃內 manifold。代表公司：台達電、光寶、奇鋐、雙鴻、健策。
- **廠房（Wattonomics S7）：** UPS、配電盤與開關設備、變壓器、母線槽、發電機、列級或機房級 CDU、冷水機、CRAH 與冷卻塔。代表公司：Vertiv、ABB。
- **跨邊界產品**（例如台達電的資料中心 UPS、Vertiv 的機櫃內產品）：個股依公司揭露拆分；無法拆時，以主要部分歸屬並在 README 列入待判斷。
