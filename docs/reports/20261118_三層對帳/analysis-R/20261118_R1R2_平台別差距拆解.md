# R1／R2 平台別差距拆解（analysis-R，2026-11-18）

唯讀分析。資料：company-models main d04f591（Siliconomics v0.20、Wattonomics v0.3.6、協調橋接 v0.3.6、markets/chip_bridge v0.2.3 dist）、Tokenomics 79f6b30（v22.0）。兩個 repo 未改任何檔案（`git status` 乾淨）。
單位：GW＝IT 關鍵電力（Tokenomics 口徑），出貨年。本報告所有計算結果都是 [Derived]；輸入的等級寫在表內或附註。
配套檔：同名 `.xlsx`（輸入頁＋公式頁，可逐格點回來源）、`scripts/`（Python 抽數與獨立重算）。

## 一、結論（先講答案）

1. **「2027 年差距八到九成在 NVIDIA」：點估計被證實，區間要修正。**
   - 用顆數重做：2027 實體 GW 總差距 15.34，其中 NVIDIA 13.31，**占 86.8%**；成本等值口徑 86.6%。落在粗算的 82–93% 內。
   - 但區間比粗算寬：Wattonomics 的 NVIDIA GW 取決於逐買方 NVIDIA 份額，模型自己給了低／高值。用這兩端算，NVIDIA 占差距 **66%–107%**。
   - 還有一點粗算沒講：Wattonomics 的 NVIDIA 拆分讀的是 Siliconomics 的逐買方金額份額（`SIF_nvsh_*`，[Interested-party]／[Assumed]），**不是 Wattonomics 自己的證據**。所以「差距在 NVIDIA」這件事，一半是兩層共用同一份份額表的結果。
   - 2026 也證實：NVIDIA 差 3.59，大於總差距 2.35（占 153%）；非 NVIDIA 反而是 Wattonomics 高 1.24。
   - 2028、2029 **無法驗證**：Wattonomics 的 NVIDIA 拆分只建到 2027（Compare 頁 F 節），這是模型結構限制。

2. **差距集中在 2027 年的 NVIDIA Rubin 與 Blackwell。** 2027 年：Rubin 差 8.15、Blackwell 差 4.63（Wattonomics 假設 2027 新增 GW 不含 Blackwell，Siliconomics 有 226 萬顆）、Rubin Ultra 差 0.52。
   - 換成顆數更直觀：Wattonomics 2027 年的 NVIDIA GW 隱含 **438 萬顆**封裝，Siliconomics 是 **912 萬顆**，差 2.1 倍。
   - 換成金額：Siliconomics 的顆數需要 NVIDIA 系統 IT 資本支出約 **1.07 兆美元**，Wattonomics 的 NVIDIA GW 只對應約 **5,880 億美元**（都以 Tokenomics 每 GW IT capex 換算）。

3. **非 NVIDIA 兩層大致相近。** 2027：Siliconomics 15.03、Wattonomics 13.00（差 2.03）；2026：7.20 對 8.44（Wattonomics 高 1.24）。平台別（AMD、TPU、Trainium、其他）在 Wattonomics 只能用「模型隱含歸屬」對照，AMD 差 2.02 主要是歸屬方式造成的，不宜解讀。

4. **往上追原因：模型內能機械算出來的只有 0.37 GW，其餘 14.98 GW（97.6%）是未解釋。**
   - 每 GW 顆數：0（兩層讀同一份 Tokenomics v22.0）。
   - 每 GW 成本（世代組合＋Wattonomics 內部兩套份額不一致）：0.27＋0.09＝0.37。
   - 年度歸屬：基準下 0；參數區間只有 ±0.48；而且 2026 起累計差距逐年擴大（2.6 → 18.9 → 33.6 → 48.4），**不可能是時差**。
   - NVIDIA 份額：只決定差距落在 NVIDIA 還是非 NVIDIA（組成效果 4.13，區間 3.25–5.01），**不改總差距**。
   - 買方覆蓋與資本支出口徑：七家 AI 占比若取高值 0.95，Wattonomics 只多 2.32 GW；是候選解釋，沒有證據支持，不歸因。
   - 剩下的「總量差」在模型內分不出是 Wattonomics 少算了買方、買方資本支出口徑偏低，還是 Siliconomics 的顆數（第三方估計，[Interested-party]）偏高。這要靠 K1 回測與 K2 獨立上線資料。

5. **R2：NVIDIA 通過，非 NVIDIA 不通過。**
   - NVIDIA 五個世代的每 GW 顆數，在 Tokenomics、Siliconomics、Wattonomics、chip_bridge 四處**逐值相同（差 0%）**；電力口徑（IT 關鍵電力、機架設計功率、PUE 與利用率不進顆數）在 Tokenomics 與 Wattonomics 有明寫。
   - chip_bridge 讀 v21.7 而非 v22.0：它讀的 8 個名稱、120 格**全部相同，造成的差異是 0**。兩版只有 6 格不同，全在 TPU、Trainium 的產出比，chip_bridge 不讀。
   - 非 NVIDIA：**三層都沒有每 GW 顆數**。Siliconomics 隱含的顆／GW 比 Tokenomics 證據資料夾的推導值高 18%–61%，口徑也沒寫。若改用證據值，Siliconomics 2027 非 NVIDIA 實體 GW 由 15.03 變 20.42（＋5.39）。兩層用同一個換算慣例，所以這不製造兩層差距，但兩層的非 NVIDIA 實體 GW 都偏低。

正值＝可解釋 Siliconomics 高於 Wattonomics 的 GW。只有能在模型內機械算出、且不依賴未證實假設的項目才算「可唯一歸因」。

說明：
- **每 GW 顆數＝0。** Wattonomics 不用顆數算 GW（它用「資本支出 ÷ 每 GW 成本」），但換成顆數時與 Siliconomics 讀同一個 Tokenomics 值。
- **世代組合 0.27。** Wattonomics 2027 年的 NVIDIA 新增 GW 全算 Rubin（VR200 94%、Rubin Ultra 6%；Players 頁註記「工作單：2027 起 VR200」），每 GW IT capex 38.34；Siliconomics 的組合含 16% Blackwell，加權後 37.35。把 Wattonomics 七家與 xAI 的付款年換算改用 37.35，GW 多 0.27。所以 Blackwell 那 4.63 GW 的平台差，絕大部分不是「成本」造成，而是 Wattonomics 根本沒把 Blackwell 放進 2027（組合假設），總量照樣由資本支出決定。
- **Wattonomics 內部份額不一致 0.09。** CapexGW 換算用的非 NVIDIA 占比（Microsoft、Meta、Oracle 等用市場值 27.3%，該值也是由 Siliconomics Units 推得；Google 75.3%、Amazon 67%）與 Compare 對帳頁的逐買方 GW 份額（Microsoft 36.5%、Meta 46.5%、Amazon 52.7% 等）不同。改成一致，總量只動 0.09（2026 −0.51）。
- **年度歸屬不能解釋。** 2026–2029 累計差距 2.57 → 18.94 → 33.61 → 48.42 GW（Siliconomics 實體累計 157.1 對 Wattonomics 平滑法 108.7），逐年擴大；單純的時差在累計上應收斂。
- **份額只管組成。** 若 Wattonomics 用 Siliconomics 的 NVIDIA 占比，NVIDIA 差距會從 13.31 降到約 10.1，非 NVIDIA 差距相應上升，總差距不變。
- **2028–2029** 除總量外無法拆；Siliconomics 這兩年還乘了係數 0.8 與 0.71（S33，[Assumed]／連續法 [Derived]），不乘係數的原始讀數是 55.1、62.7 實體 GW。
