## 4. 這個結果要怎麼讀

- **判定翻轉有一部分是時點效果。** 第二讀數的「最近一季」由 Q2（中點約年中）換成 Q3（中點比年中晚一季）。營收逐季成長的年度裡，最近一季年化高於全年平均，差距偏小。主讀數的線性分攤偏差方向相反，差距偏大。真實缺口落在 −9.7% 與 −23.9% 之間的哪裡，這兩個讀數分不出來。
- **判定對每 IT GW NVIDIA 營收（n2）的取值敏感：** 低值時兩讀數都在門檻內，高值時兩讀數都超過。
- **第三季不再是樣本外。** 2027-02-28 的期限裁定若要用第三季當證據，它已經先進了判定。解除時的樣本外結果保存在規則 C10 的保留清單。
