## 2. 每家必做（同輪，缺一退件）
1. **版面 v1.3**（A–I，含 G、H 位置）：章節順序、標準損益表、RevDCF 頁、估值章四個目標價圖置頂、敏感度章低／高案主圖置頂；`check_layout_v13 --xlsx` 全過。已是 v1.3 者（CoreWeave v5.0.2、Oracle v0.5.1、Anthropic #469）只補缺項。
2. **Coord 頁「三層協調」節：**
   - **讀取層級：** 本模型讀哪一層、哪一版、哪些名稱（硬體股：Siliconomics v0.19；算力買賣方：Tokenomics v22.0／Wattonomics v0.3.2 快照，若模型仍讀舊快照，寫明版本、不在本輪換快照）。自層級讀入的同源值只列在此節。
   - **C0（實績）表：** 個股側＝公司實績或法定揭露（財報、10-Q／8-K、法說揭露的分部數字），寫期間、口徑、出處、等級；層級側＝同口徑的層級隱含值，儘量連格。主讀數＝2026 年已公布期間累計 vs 層級 CY2026 × 月數 ÷ 12；第二讀數＝最近一季 × 4 vs 層級 CY2026（偏誤方向依季中點，不得寫「夾住真值」）。兩者都超過 ±15% 且同號才「對帳中」，只一個超過為「時差邊界（參考）」。
   - **同源校準：** 層級值若由本公司模型校準後寫入上層（例：Wattonomics 玩家 GW 讀公司目標、Siliconomics 份額由個股錨點反推），判定標「參考（同源校準）」，結論寫「無可比實績（層級值同源）」，可見說明寫明哪些量消去、實際檢驗什麼。
   - **算力買賣方的對象（建議，建置時查證）：** 資本支出實績 vs Wattonomics 該玩家資本支出；在役／簽約電力 MW 實績 vs Wattonomics 該玩家上線 GW；AI 營收或 run-rate 實績 vs Tokenomics 每 GW 營收 × Wattonomics GW。玩家不在 Wattonomics 名單者寫「無可比實績（層級無此玩家）」。
   - **兩層之間差距只列參考；外部估計只列參考。**
3. **硬體股兩讀數（ter、amkr、cohr、alab）：** `tools/coord`：主引擎掛鉤（依模型 Wattonomics 錨定參數名）、`alt_run.py <資料夾>`（`LO_PROFILE` 私有設定檔）、`add_sheet`＋`stamp`、`inject_html`；`siliconomics/builder/seed/coord_meta_v0.19.json` 的 `hardware_companies` 加入本資料夾並重匯 `baseline_status.json`（多家同時改此檔會衝突：只在 PR 說明列出，由主控合併時統一加入）。不要建 `co_flag` 具名範圍。算力買賣方不做兩讀數。
4. **不變性：** 既有數值、目標價、評等不變（`tools/xlsx_diff.py` 逐格；只允許版號、build_id、新增格、判定欄文字）；兩讀數為新增。EPS 口徑標明（基本／稀釋）。
5. **版號：** 每家升一個修訂版號（先查 open PR 是否占用）；舊 dist 移 `dist/_待刪除/`；README 新增一節（依據、做法、實績與出處、判定、驗證）。
