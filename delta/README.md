## 最大限制

- 「AI 相關」是否含液冷，公司說法不一致：本版讀為不含（Sens 另列）。
- 2028 年起每 kW 內容（800V）與份額相對值是 Assumed。
- 部署 GW 以 VR200 每 GW IT 資本支出換算；ASIC 機架每 GW 資本支出較低，GW 可能低估。
- 十年 P/E 只有一個來源，2016–2019 年是 AI 前的低倍數（15–17x），規則值可能低估 AI 期的合理倍數。前瞻 P/E 歷史待 Bloomberg。
