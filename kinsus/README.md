3. 營業費用彈性 0.6、稅率 12%（1H26 只有 6.9%），對 FY2028 EPS 各有約 −7%、−10% 的空間。

- v0.4 起為標準版 FCFF＋WACC（見上方 v0.4 一節）；以下為 v0.1–v0.3.1 的股東現金流法說明，數字為當時撰寫。

- 期間：FY2027–32 明確期，加上永續價值。

- 2026–28 年擴產資本支出（每年 160–170 億）壓低前段現金流：情境 B 每股股東現金流 FY2027 10.37、FY2028 19.77，FY2029 起才接近 EPS。

## 最大限制

- 公司不揭露 ABF／BT 與 AI 拆分；產品組合取媒體與法說摘要（區間），AI 占比取高盛轉述；加速器、CPU 與網通載板的拆分是校準殘差。
- **份額衝突**：券商稱景碩 Rubin GPU 份額 15–20%，但 Ibiden（70%）、欣興（25–30%）、南電（2–4%）模型的份額已合計 94–97%；本模型 GPU 取剩餘空間，Sens 列券商說法為高值。若券商說法成立，需回頭下修 Ibiden 或欣興模型的份額（跨模型一致性問題）。
- Vera CPU 份額、CPU 顆數比例與 CPU 載板金額比是公司說法、Analogy 與 Assumed；Ibiden 模型的每顆 NVIDIA 載板金額可能已含部分 CPU 載板（小幅重複計算）。
- 毛利只用現金流通率近似，沒有建分廠稼動率與 K6 爬坡良率；T-glass 供給可能限制實際產出。
- 客戶贊助設備（高盛轉述）的金額與會計處理未知；若屬實，資本支出可能高估、DCF 偏低。
- 晶碩持股比例由非控制權益推得（約 31%），原文未取得；DCF 的折舊與資本支出含晶碩，淨利只計歸屬母公司。
- 公司數字取自資料商與媒體轉載，公開資訊觀測站原文待人工複核。
- 共識：FactSet 為 2026-06；主串提供的共識 EPS（FY2026 10.42、FY2027 26.47）原始口徑未查證。
- 十年 P/E 2023–24 年約 900 倍、2019 年虧損不計，與盈餘反向。
