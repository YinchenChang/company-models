**核心問題：在市場層 TPU 顆數（CY2027 5.5 百萬顆）與 CPU 對 TPU 配比口徑下，創意 FY2027–28 的 CPU 顆數與 EPS 離法人估計（CPU 400 萬顆、FY2027 EPS 94–139 元）多遠；差距要靠配比、份額還是車用補上；現價約 90 倍前瞻 P/E 與同業差多少。**

**投資建議：放空**（依上檔空間固定規則：加權目標價上檔空間 −47.7%，落在 −25%～−50%）。

1. 目標價 NT$3,968（DCF 2,268、Comparable 相對倍數調整後 5,668 各半），比現價 7,585（2026-10-22）低 47.7%，級距 −25%～−50%，投資建議維持放空。v0.2 滾入 3Q26 實績（營收 187.5 億、毛利率 20.58%、EPS 16.95；前三季 EPS 40.84）：毛利率與營業外收入高於原假設，FY2026 EPS 60.7 → 62.2，加權目標價 3,911 → 3,968（+1.5%）。

3. 4Q26 仍為假設（營收季增 35%、毛利率 18.5%；公司未給季度區間指引）；CPU 對 TPU 配比是 FY2027 EPS 最敏感的變數（Sens 頁）。下一個檢驗點是 10–12 月月營收與 4Q26 財報（2027-02）。

  - 十年 P/E 有兩個來源：companiesmarketcap（2016–2025）與自算（digrin 12 月股價 ÷ HiStock EPS；2016–2017 EPS 未找到）。

目標價方法的偏誤方向：
- CPU 顆數綁 TPU 顆數與配比，沒有一般運算 Axion 的獨立成長；FY2030 起又只用收斂法，所以 DCF 偏低估。
- 同業倍數遠低於創意本身與歷史倍數（十年中位數約 50 倍），所以 Comparable 偏低估。
- 單一客戶集中的下行只在情境 C 反映。

本版未做先驗，無 Andy 合理 P/E 對照。

## 最大限制

- 公司未揭露客戶名稱，也未揭露 CPU、AI ASIC、車用的營收金額、每顆 CPU 營收、HBM 採購方式、下一代 CPU 的設計夥伴。配比、份額、拆分與毛利率都是 Assumed。
- 公司自 2026 年起不給季度區間指引。3Q26 的毛利率與費用只有方向性說法，財報內容多為媒體轉述。3Q26 財報與法說在 **2026-10-29**（stockanalysis），屆時更新錨點；11 月 10 日前公布 10 月營收。
- 1Q、2Q26 的稅前利益與所得稅未找到，用近 12 月稅率推估。FY2025 稅前利益由 stockanalysis 的稅前淨利率推得。
- FY2026 共識的資料日是 2026-09-04；FY2027 起的共識為付費資料，只有媒體轉述（Visible Alpha 94.24、優分析 139.12）。
- 十年平均淨利率未找到；2016–2017 的自算 EPS 未找到。十年 P/E 多為 NRE 主導期，不一定適用於現在的 turnkey 結構。
- R4 產業部署路徑未建。
