## 1. 問題與原因（10-Q Note 5 原文數字，千美元／千股）

| 項目 | 1Q FY27 |
|---|---|
| 淨利（基本） | 1,594,205 |
| − 特別股股利 | 75,796 |
| − 分配予參與證券（強制可轉換特別股） | 251,561 |
| ＝ 歸屬普通股淨利（基本） | 1,266,848 |
| ＋ 分配予參與證券 | 251,561 |
| ＋ 可轉債利息（稅後） | 18,041 |
| − 稀釋時重分配予參與證券 | 228,164 |
| ＝ 歸屬普通股淨利（稀釋） | 1,308,286 |
| 基本加權股數 | 658,128 |
| ＋ 可轉債（if-converted） | 73,803 |
| ＋ 其他稀釋證券（RSU、選擇權等，合併一列） | 17,420 |
| ＝ 稀釋加權股數 | 749,351 |
| EPS 基本／稀釋 | 1.92／1.75 |

- 強制可轉換特別股**不是** if-converted 進稀釋股數，而是以兩類法參與盈餘分配；參與比例反推：基本 251,561 ÷（1,266,848＋251,561）＝16.57% → 658,128 × 16.57% ÷ 83.43%＝130.68 百萬股；稀釋 228,164 ÷（1,308,286＋228,164）＝14.85% → 749,351 × 14.85% ÷ 85.15%＝130.68 百萬股＝4,312,500 股 × 最低轉換率 30.3040（10-Q 特別股附註）。
- 因此公司稀釋 EPS ＝（淨利 − 特別股股利＋可轉債稅後利息）÷（稀釋股數＋130.686 百萬參與股數）＝1,536.45 ÷ 880.04＝1.7459 → 1.75。
- 前版模型 EPS＝（淨利 − 特別股股利）÷ 稀釋股數＝1,518.41 ÷ 749.35＝2.03（高 15.8%；前版 Q 頁 `q1a_epsm`），差在漏了參與股數（分母少 130.7 百萬股）與可轉債利息加回（分子少 18.0 百萬美元／季）。
