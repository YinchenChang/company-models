## ④ η 拆解（診斷；EtaDiag，對照 Excel ③）
η（2025）＝token 換算推論 GW 0.182 ÷ 支出換算推論 GW 0.345 ＝ **0.527**。

| 因子（η 的方向） | 基準 | 低 | 高 | 標記與依據 |
|---|---|---|---|---|
| f_P 計價口徑＝每 GW 合約實付 9.36 ÷ TK 持有成本（加權）7.57 | 1.237 | 0.720 | 1.767 | Analogy（TK 持有成本；低／高＝TK 低／高成本情境） |
| f_U 利用率＝TK 實際利用率 0.41 ÷ 基準 0.60 | 0.683 | 0.500 | 1.083 | Analogy（TK `IF_UtilActual` 0.30–0.65；非 Anthropic 實測） |
| f_W 工作負載（層級）組合＝TK 參考組合產能 ÷ 本模型組合產能（機隊加權） | 1.399 | — | — | Derived（無區間；Inputs 層級組合區間未接入） |
| 輸入輸出組合 | 無法分離 | | | 每任務 token 已直接取自 TK 任務模板，並入殘差 |
| 已解釋部分 | 1.183 | 0.504 | 2.679 | |
| **未解釋殘差＝η ÷ 已解釋部分** | **0.446** | 0.197 | 1.047 | 殘差，非獨立估計 |

讀法：前三項合起來預期 η 約 1.18，實際只有 0.53，差 0.446 倍沒有被解釋。**但區間端點會翻轉讀法**：f_P、f_U 取高端時乘積 2.68，殘差 1.05（幾乎沒有未解釋）；取低端時殘差 0.20。因此「殘差約 0.45」是基準值，不是穩健結論；能確定的只有方向（基準下已解釋部分高估了 η）。

**並列 TK L1_Gap*（OpenAI 口徑，Analogy；TK 方向＝支出路線 ÷ token 路線，與本表互為倒數）**：計價口徑 0.85（本模型 1 ÷ f_P＝0.81）、利用率 1.72（含生產折減 0.85；本模型 1 ÷ f_U＝1.46，未計生產折減）、每則提示 token 1.305 與請求形狀 1.0（本模型無法分離）、未解釋 5.46（區間 1.04–15.8；本模型 1 ÷ 殘差＝2.24）。利用率與殘差兩項方向一致（> 1：支出路線 GW 大於 token 路線 GW），計價口徑兩邊都 < 1（0.81 對 0.85），整體量級不同，只作並排。

**版本變動小表（回答「TK 版本變動是否被殘差吸收」）**：

| | v0.1.1（TK v5.26） | v0.1.2（TK v18.0） | v0.1.3（TK v19.0） | v0.1.2 ÷ v0.1.1 | v0.1.3 ÷ v0.1.2 |
|---|---|---|---|---|---|
| η（2025） | 0.888 | 0.527 | 0.527 | 0.594 | 1.000 |
| f_P | 1.189 | 1.237 | 1.237 | 1.040 | 1.000 |
| f_U（三版一律 0.41 ÷ IF_Util） | 0.683 | 0.683 | 0.683 | 1.000 | 1.000 |
| f_W | 1.413 | 1.399 | 1.399 | 0.990 | 1.000 |
| 殘差 | 0.774 | 0.446 | 0.446 | **0.576** | 1.000 |
| 機隊每 GW 付費產能（M tok/GW/年） | 4.57e9 | 7.70e9 | 7.70e9 | 1.686 | 1.000 |

**答：是，v5.26 → v18.0 的變動幾乎全被殘差吸收。** 原因是機制性的：TK 每 GW 產能上升 1.69 倍使 token 換算 GW 下降（η ∝ 1 ÷ 產能），而 f_P、f_U、f_W 都是「比值」，TK 產能整體放大時比值不動，所以全落在殘差。v18.0 → v19.0 全部不變。這代表：**η 在本模型中其實是「TK 絕對產能水準」的補償係數**，拆解的前三項無法呈現它。是否加第四因子「TK 絕對產能水準」見 ⑧ 待決。
