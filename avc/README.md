## 重點觀察

1. 目標價 NT$3,966（DCF 3,002、Comparable 4,929 各半），比現價 3,145（2026-10-22）高 26.1%，級距 25%–50%；Comparable 單獨為 56.7%。主因是 EPS：本模型 12 個月後前瞻 EPS 179.1 比共識前瞻 EPS 132.6 高 35.1%（兩者期間差約一年；FY2027 B 163.2 比高盛 154.8 高 5.4%），同業（雙鴻、健策、Vertiv、台達電）前瞻 P/E 中位數 27.5 倍略高於現價隱含 23.7 倍；DCF 只有前瞻 EPS 的 16.8 倍、比現價低 4.5%，上檔空間全由 Comparable 拉動。
2. v0.2.1 起液冷滲透率依情境字母（A 高、B 基準、C 低）：FY2027 EPS A／B／C＝174.7／163.2／145.8（原三情境同為 163.2），FY2028＝224.8／177.5／130.4（原 209.7／177.5／143.4）；加權目標價由 3,956 升到 3,966，上檔空間由 25.8% 升到 26.1%，離買進與中立的界線 +25% 很近。
3. 每架液冷內容調整是最敏感的變數：調整 1.0（只有橋接表的機架內液冷）時 FY2028 EPS −18.2%，2027 1.6、2028 1.8 時 +18.3%。10 月營收（約 11-10）與 3Q26 財報與法說（預計 11 月中）可檢驗 2026 年液冷占比（本模型 32%，券商 30–35%）。
