## 命題一句話
AWS 的 AI 容量（Trainium＋NVIDIA）能否以高於資金成本的報酬變現，零售與廣告的現金流能否支應資本支出。

## 核心問題
FY2028 AWS 營業利益率與自由現金流（扣股利後）是否轉正並維持。

## 與 v0.2.2 的差異
- 營收主軸由「AI 雲端 MW × 每 MW 收入＋成長率線」改為**官方分部**（North America、International、AWS）＋**10-K 營收線**；命題只驅動 AWS 之下的 AWS AI 子列。
- AI 資本支出接到**折舊與分部營業利益**（對外 → AWS、自用 → 北美／國際），不只接現金。
- 融資瀑布、站點、租賃承諾、RPO 等 CRWV 模組移除；評價改為 DCF 50%＋分部加總 50%，情境加權。
- 目標價 v0.2.2 基準 201.71 → v0.3 加權 215.58；以讀法 2 比較為 v0.2.2 220.09 → 215.58（拆解見 v0.3 報告第 6 節；v0.3.1 的 Recon 頁 D 節改為 v0.3 → v0.3.1 拆解）。
- 舊引擎（segA–E.js、tail.js、build_xlsx.py、company.json、kspec.py、scripts/ 等）移至 `legacy_v0.2/`（保留不刪；v0.2.2 交接檔仍在 `docs/handoff/`）；舊成品移至 `dist/_待刪除/`。

## 已知限制
1. 公司未揭露 AI 在役 MW、對外比例與 AI 營收：AWS AI／AWS 其他的歷史分拆為估計（6/30 年化 20.1 vs 公司「>25」）。
2. 分部與營收線共識：未找到；合併共識為財報前（MarketScreener 10-08、S&P 10-26）。
3. 同業倍數沿用 2026-10-07；kd 以 rf＋AA 利差代理。
4. 模型 EBITDA（PL 頁）只加回 PP&E 折舊且不加回 SBC，低於供應商口徑；分部加總另用 SBC 加回口徑。
5. 10-Q 2026Q3 未取得：債務面額（推導 181.09）、融資租賃、分部折舊、在建、RPO 附註沿用 2026Q2 或推導。
6. 公司說 AWS 2027、2028 年各成長 40% 以上，模型 B 為 28%、24%（只作驗證列）；模型 Q4 26 AWS 45.1 低於 Q3 實績 46.0（AWS 其他成長起點維持 FY2025 年增，Sens 改用 9M26 為 +14.7）。
7. In 頁 D／F 只用於 Sens；共識目標價與 S&P 營收／EPS 的區間只作對照，不進模型（只被 Recon、README 與 Val 顯示格引用）。
