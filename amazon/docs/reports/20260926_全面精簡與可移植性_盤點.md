## 2. HTML 目前的即時輸入功能（請 Andy 逐項決定）

「預算」＝建置時以 LibreOffice 對每個組合重算 Excel、匯出 JSON，HTML 切換顯示。

## 5. 具名範圍（Excel → JSON → HTML 介面）規劃

- **範圍**：HTML 要顯示的輸入與輸出全部加名稱（Andy 決定，不限數量）。預估約 300–400 個：逐年數字一列用一個名稱（5 格），不逐格命名。
- **命名規則**：使用英文（ASCII），例如 `in_Price`、`out_TargetPrice`、`out_Revenue`（5 期）、`q_Revenue_Model`（6 季）。Excel、LibreOffice、JSON 都穩定支援；中文名稱在清單表中對照。
- **名稱清單表**：新分頁「名稱清單」，欄位為名稱、中文標籤、單位、類型（輸入／輸出／文字）、位置（分頁!範圍）、HTML 顯示位置（5b 填）。建置時自動產生，並檢查每個名稱都指向有效範圍。
- **核對**：B 階段新增「名稱清單的每個名稱都能從重算後的 Excel 取值」檢查，作為 5b 匯出 JSON 的前置。
