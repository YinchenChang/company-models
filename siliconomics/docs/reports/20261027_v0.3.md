# Siliconomics v0.3 報告（2026-10-27）

**分支：** `claude/siliconomics-v0.3`　**成品：** `siliconomics/model/20261027_Siliconomics_v0.3.xlsx`

## 做了什麼、為什麼

運算層的兩組行業變數原本「住在某家公司模型裡」，其他公司再去讀那家的成品：
- **加速器每顆售價**（AMD、TPU、Trainium、其他 ASIC）原在 NVIDIA 模型；**ASIC 核心價與 HBM 代購比例**原在 Broadcom 模型。→ 移入本庫 In 頁 M6。
- **ASIC 設計服務份額**（Broadcom、Marvell、聯發科、世芯）分散在四家模型，各自只檢查看得到的那幾家。→ 移入 M7，新增 ShareTbl 頁把同一平台的份額排在一起，Checks K6 檢查合計 ≤ 100%。

數值與文字逐字搬入，原模型改讀本庫，所以**本版不改任何數字**。
