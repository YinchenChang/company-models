# Siliconomics v0.5 報告（2026-10-27）

**分支：** `claude/siliconomics-v0.5`　**成品：** `siliconomics/model/20261027_Siliconomics_v0.5.xlsx`

## 做了什麼、為什麼

1. **ABF 載板的行業變數移入本庫（M13）。** 原本 Ibiden 模型決定自己的份額與價格路徑，欣興、南電、景碩再從上游公司的 dist 層層轉讀，只有景碩看得到全部份額。現在 Ibiden 份額與相對值、非 NVIDIA 權重、每顆載板金額年增、價格溢價指數，以及三家台廠的 NVIDIA 與非 NVIDIA 份額，都集中在本庫。數值與文字逐字搬入。
2. **載板份額表與加總檢查（CF20）。** ShareTbl 新增兩張表，Checks K6-abf 檢查合計不超過 100%，全部 OK。
3. **ABF 外部缺口只留一條路徑（CF03 部分）。** 新增 `abf_gap_26–28`：基準取兩來源中點，低／高為各來源值。
4. **CoWoS 供需輸入移入本庫（M14）。** 包括每片晶圓封裝數（10 個平台）、其他用途、台積電年底月產能、委外補充、Morgan Stanley 需求，原在台積電模型。三列 Assumed 補上區間，兩列補上來源欄，基準不變。
5. **留在公司模型。** 每顆載板金額 `v26` 以 Ibiden 營收 ÷ 70% 校準，每顆台積電內容 `ct_*` 是台積電的營收變數，兩者都屬公司變數。
